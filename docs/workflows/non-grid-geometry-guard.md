## 问题与节点位置

景田店 / 张小飞的白墙正面图，拆分后与母图裁切区域逐像素一致；后续 GeoCalib 将横滚估计为 6.01°、俯仰估计为 -15.29°，不确定性分别为 5.20°、8.26°。旧流程虽然提示不确定，仍应用变换。墙面修正证据不足时保留了这个结果，最终把接近竖直的人物和水平踢脚线一起变斜。

新节点位于：

```text
分类 → 单人/硬拼接拆分 → 背景过滤 → 单图相机/网格/墙面标准化
    → 可疑非网格几何检查与回退（v4标准化入口默认执行）
    → 同店同名共同取景与统一尺寸 → 训练阶段标签及后续拼接
```

开发实现：[scripts/body_scan_geometry_guard](../../scripts/body_scan_geometry_guard/README.md)。新v4归档负责默认串接；现有开发入口、网站及原有最佳实践目录保持原样。

## 策略

1. 网格、跳过、待复核项保持原有结果。
2. 不能因存在“角度不确定”警告就统一撤销校正。仅在变换明显且相对估计误差较大时进入额外证据判断：横滚 ≥ 3° / 俯仰 ≥ 12°，相应不确定性 ≥ 该角度绝对值的一半。此比例为工程筛查阈值，不作概率解释。
3. 独立检查既有高置信墙面语义证据对应的真实测量线段。可信、原本近水平/竖直的结构经过变换后明显变斜，即使相机自身置信较高也应回退。原本存在透视的斜线不因此被强制拉平。模型选择出现未知编号、横竖方向冲突、置信不足时，不采用该方向的证据；不影响另一个方向的合法证据。
4. 变换明显且不确定、又缺乏足够横竖两族背景证据支持时，保留原图方向。人物自身的肩线、躯干方向不作为扶正标准。
5. 回退后基于单位几何矩阵重新计算肩髋及取景，输出真实有效矩形，再运行原有整组展示节点。历史矩阵存入 `previous_geometry`，不会叠加使用旧变换。
6. 通过检查的文件直接复制；源文件与旧结果在运行前后均核验 SHA。已有同组背景配准如遇回退，需要重算配准，当前记录待复核并保留原成品，不能静默复用旧坐标参数。本轮未遇此情况。

本轮无需新增大模型请求，复用原图绑定的墙面语义审查与线段选择。张小飞原来的选择中存在把横线编号当竖线的错误；新检查隔离该方向的错误后，仍能利用合法水平线确认退步。不会让模型直接输出或批准变换矩阵。
