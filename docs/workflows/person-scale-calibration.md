# 同人尺度校准与共同取景

状态：独立实验，先验证景田店张小飞、石厦店黎国萍、郑远晨、冯雪奕、潘艺文五组28张。尚未覆盖全部历史素材，也未更新冻结最佳实践或网站。

## 节点位置

```text
分类/硬拼接拆分 → 单图最佳实践v4（背景几何 + 矩形有效区域）
                         ↓
                  同人尺度校准实验
                  ↖ 旧版完整度与展示证据（绑定输入SHA，保护完整头脚）
                         ↓
               原有同组展示节点（一人一画幅）
                         ↓
            新旧对照 / 人工复核 / 后续拼接
```

尺寸、位置、人物尺度是三个独立约束：同一像素画幅不保证人物一样大；肩部对齐只约束位置；本节点增加整组尺度参考，并将每张的缩放因素写进坐标变换链。

## 实施原则

- **共同单位**：至少两张中立正/背图；先获得整组可靠肩髋、髋膝、膝踝的参考长度。仅有被遮挡腿部时不取消可靠肩髋证据。侧面与抬臂不建立中立参考。
- **同场景传递**：Qwen确认同一实际背景且人物贴近墙之后，网格实测格距或墙面SIFT配准传递尺度。网格格距在已批准的校正坐标中计算，不直接使用原始图的像素间隔。
- **跨场景传递**：通过同人的可靠身体分段连接背景，不假设不同网格板格距相同，也不把衣服松紧当尺度。
- **独立缩放和定位**：只做等比缩放及平移。抬臂照片通过髋部和中立躯干参考定位，不把耸起的肩当成自然肩高；真实身体角度不变。
- **控制改动**：2%内保留；参考尺度一致性界限8%；身体证据相对候选差异超过5%提示复核、超过12%保留；候选倍率相对旧版只接受0.8–1.25。新增补边超过4个百分点或新裁掉完整头脚也保留。这些是实验门槛，不是人体测量误差保证。
- **共同取景**：调用未修改的同组展示节点。每人只有一个裁剪框、一套输出尺寸及共享展示比例；原图采样使用合成矩阵，避免反复缩放成品。

## 测试与限制

测试包含：语义结果完整性、头部/外轮廓不参与尺度、腿部遮挡、抬臂在两类背景中一致处理、两参考要求、单一分段不足、证据冲突保留、参考间小误差不互换、保持身体角度与等比、避免新增头脚截断。

远程实图同时检查输入指纹、保留图字节、相机矩阵、矩形有效像素和最终一人一画幅。以a0101/a0107为重点，同时查看四个其他组。张小飞组证据不足时保留，不能为了覆盖率放松检查。

本轮发现过放大导致头顶余量不足的候选，最终增加完整头脚保护。保护使用SAM以肩髋正向提示测得的主体轮廓，再结合旧版完整度标签；VLM粗框只作为分割提示，不能直接作为裁断边界。中间试跑目录保留供审计，最终目录和数值以[机器验证记录](../../scripts/body_scan_person_scale/validation.json)为准。

报告中的“肩髋长度差”只是二维辅助诊断，会随抬臂/侧身变化；“网格尺度差”只检验同背景尺度。没有真实身高、拍摄距离真值，不能宣称所有照片的人体比例误差已低于5%。
