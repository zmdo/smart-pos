# 同人尺度校准与共同取景

状态：已归档为[同组展示v3最佳实践](../../best-practices/body-scan-group-display-v3/README.md)，初始来源`1370541`，现已接入 6008 网站。初始实验覆盖五组28张；2026-11-08 的微小边界修复另回归景田店九组42张，尚未代表全部历史素材。旧v2仅在 Git 历史保留。

推荐入口`best-practices/body-scan-group-display-v3/run.sh`串接基线证据→尺度校准→最终共同取景。可以复用指纹匹配的基线；省略时自动生成。初始归档独立验证见[validation.json](../../best-practices/body-scan-group-display-v3/validation.json)；新增边界复核见文末。

## 节点位置

```text
分类/硬拼接拆分 → 单图最佳实践v4（背景几何 + 矩形有效区域）
                         ↓
                  同人尺度校准节点
                  ↖ 旧版完整度与展示证据（绑定输入SHA，保护完整头脚）
                         ↓
               原有同组展示节点（一人一画幅）
                         ↓
            新旧对照 / 人工复核 / 后续拼接
```

尺寸、位置、人物尺度是三个独立约束：同一像素画幅不保证人物一样大；肩部对齐只约束位置；本节点增加整组尺度参考，并将每张的缩放因素写进坐标变换链。

## 实施原则

- **共同单位**：至少两张中立正/背图；先获得整组可靠肩髋、髋膝、膝踝的参考长度。仅有被遮挡腿部时不取消可靠肩髋证据。侧面与抬臂不建立中立参考。
- **同场景传递**：Qwen确认同一实际背景且人物贴近墙之后，网格实测格距或墙面SIFT配准传递尺度。网格格距在已批准的校正坐标中计算，不直接使用原始图的像素间隔。
- **跨场景传递**：通过同人的可靠身体分段连接背景，不假设不同网格板格距相同，也不把衣服松紧当尺度。
- **独立缩放和定位**：只做等比缩放及平移。抬臂照片通过髋部和中立躯干参考定位，不把耸起的肩当成自然肩高；真实身体角度不变。
- **控制改动**：2%内保留；参考尺度一致性界限8%；身体证据相对候选差异超过5%提示复核、超过12%保留；候选倍率相对旧版只接受0.8–1.25。新增补边超过4个百分点或新裁掉完整头脚也保留。这些是实验门槛，不是人体测量误差保证。
- **共同取景**：每人只有一个裁剪框、一套输出尺寸及共享展示比例；原图采样使用合成矩阵，避免反复缩放成品。原规划器的裁剪约束不变，微小粗框冲突允许经过像素证据复核后重新规划。

## 测试与限制

测试包含：语义结果完整性、头部/外轮廓不参与尺度、腿部遮挡、抬臂在两类背景中一致处理、两参考要求、单一分段不足、证据冲突保留、参考间小误差不互换、保持身体角度与等比、避免新增头脚截断。

远程实图同时检查输入指纹、保留图字节、相机矩阵、矩形有效像素和最终一人一画幅。以a0101/a0107为重点，同时查看四个其他组。张小飞组证据不足时保留，不能为了覆盖率放松检查。

本轮发现过放大导致头顶余量不足的候选，最终增加完整头脚保护。保护使用SAM以肩髋正向提示测得的主体轮廓，再结合旧版完整度标签；VLM粗框只作为分割提示，不能直接作为裁断边界。中间试跑目录保留供审计，最终目录和数值以[机器验证记录](../../scripts/body_scan_person_scale/validation.json)为准。

报告中的“肩髋长度差”只是二维辅助诊断，会随抬臂/侧身变化；“网格尺度差”只检验同背景尺度。没有真实身高、拍摄距离真值，不能宣称所有照片的人体比例误差已低于5%。

权威入口及复现命令见[最佳实践](../../best-practices/body-scan-group-display-v3/README.md)；原独立实验的文件职责和验证记录仍见[开发脚本说明](../../scripts/body_scan_person_scale/README.md)。

## 2026-11-08：微小边界冲突复核

唐怡婷组的 `a0078` 被 VLM 估计头顶到 26.38px，共同有效矩形上沿 28.50px，2.12px 冲突使六张全部待审核。实际 SAM 轮廓最上像素中心为 33px；加像素边缘和 2px 余量后，保护上沿为 30.50px，仍在共同框内。因此重新测量边界即可恢复，不必撤销人物尺度校准或丢掉限制画幅的另一张图。

流程为：原规划 → 仅小纵向完整头脚冲突 → 可靠 SAM 测量（保存掩码与 SHA）→ 整组原规划重验 → 采用或维持待审核。只改引起冲突的边界证据，不修改语义标签、有效区域、人体倍率与共同取景；正常组不会增加分割请求。大冲突、肩髋冲突、低质量分割、贴边/余量不足、粗框与轮廓大幅分歧仍停止。

六张恢复同一 768×1792，纵向展示系数 1.07241173；其他八组36张的显示图/等比参考字节和规划完全一致。边界新增9项回归，连同既有尺度/取景/封面测试共71项通过。记录见[机器验证](../../best-practices/body-scan-group-display-v3/boundary-recheck-validation.json)。

## 2026-11-08：尺度冲突检查与共同网格回退（已撤销，历史记录）

上述边界修复没有改变旧人物倍率。随后确认唐怡婷黑衣正面偏大：人体分段建议与背景建议差约21.4%，旧检查却把人体建议与所选人体倍率自身比较，记成0。现已区分两个指标：`body_background_disagreement` 比较独立人体/背景中位数，`body_selected_scale_disagreement` 比较人体/最终倍率；可靠背景冲突或背景内部冲突阻止实质的人体单独缩放。

只有旧缩放方案使同网格组的格距差距进一步扩大超过3个百分点、且有超过12%的尺度冲突时，才触发共同网格回退。要求全部同一可靠网格、贴墙、置信度至少0.90、至少3张及2张中立参考。共同格距从各图基线格距中位数开始；如果头脚保护或最多4个百分点新增补边无法满足，在共同倍率上最多±5%、每步1%寻找可用值。所有图同步采用同一格距，单图仍只等比缩放，保留肩部锚点；整组有一张不能通过则不部分应用。

唐怡婷最终共同格距44.2827px（中位数基础上统一+2%），同一画幅768×1689；黑衣正面相对上一成品所用尺度缩小约17.5%，白衣正面相对基线仅+0.18%。网格格距离散由38.57%降到数值误差范围内；这只说明背景尺度一致，不是实际人体尺寸的精度保证。回退结果保留尺度复核标记。

九组42张重跑，其他八组36张标准化、显示和等比图字节均不变；83项节点测试通过。部署时继承原阶段标签和用户审核，重新绑定新图，不再调用阶段判断模型。代码、门槛与验证见[权威说明](../../best-practices/body-scan-group-display-v3/README.md)和[实施记录](../design/common-grid-scale-recovery/IMPLEMENTATION.md)。


## 2026-11-08：独立提案保护与防劣化（当前）

共同网格方案只验证了背景尺度一致与其他会员不变，未保护同组正常视图。实测白衣侧面放大14.3%、白衣背面放大9.7%，背面由缺脚变为缺小腿，继而改变整组画幅及纵向展示系数。该整组回退已移除。

当前顺序：原尺度求解 → 稳定同网格参照区间与可靠肩髋证据分别检查 → 只取消同时加重两种偏差的单图提案 → SAM保护旧成品所有可见纵向范围（含部分身体）→ 发生否决的组保留安全的原共同框/肩位/尺寸/展示比例 → 正、侧、背逐图回归及成品重建。

这里取消提案是回到该节点输入，不是推算一个新的“完美倍率”。原图关键点、相机几何和训练前后标签不变；不足以确定新尺度时保留并待审核。基线不足、原共同框不可安全复用时保留诊断，不能通过缩短身体更改整组版式。背景和人体分段的置信度都不等于真实人体测量精度。

九组42张验证，只有a0078相对劣化前版本改变，余41张标准化/显示/等比像素一致；唐怡婷共同768×1792、肩位与1.07241173展示系数恢复。92项自动测试覆盖单证据不能否决、参考质量与隔离、缺失身体不继续裁剪、旧成品保留范围、旧框与原图绑定。实施和发布见[修复记录](../design/independent-scale-guard/IMPLEMENTATION.md)。
