| 工作流 | 状态 |
| --- | --- |
| [体测图分类、硬拼接拆分、标准化与同组展示](body-scan-processing.md) | 已记录完整节点衔接；拆分和标准化已有最佳实践，同组展示为独立实验，统一编排尚未实现 |
