# 工作流设计

记录已确认的处理流程、节点职责和异常分支。文档中的设计状态与实际实现状态分别说明。

| 工作流 | 状态 |
| --- | --- |
| [体测图分类、硬拼接拆分、标准化与同组展示](body-scan-processing.md) | 已记录完整节点衔接；拆分、标准化v4、同组展示v3均有最佳实践，完整编排尚未实现 |
| [同组统一取景与展示版](group-display.md) | 当前v3先共同尺度校准，再复用v2的一人一画幅取景；旧v2及其验证记录保留 |
| [训练前后标注](training-phase.md) | 独立节点；左右拆分左前右后，无标记则同人同姿势外观比较并换序复核；保留依据和未知项 |
| [拍摄批次与多朝向训练阶段标注](training-phase-sessions.md) | v2独立方案；先复核批次归属，再按清楚变化或多个朝向一致证据采纳；保留v1，不再使用0.8硬门槛 |
| [全量门店素材与双视觉模型评测](full-dataset-model-evaluation.md) | 只处理门店目录；179张图片全部覆盖，82张成品；相同输入比较DeepSeek与Qwen，保留失败、冲突和负对照 |
| [非网格相机校正检查与回退](non-grid-geometry-guard.md) | 五组28张验证后已归档为单图标准化v4最佳实践，推荐入口默认执行检查；旧v3及其他最佳实践保留 |
| [同人尺度校准与共同取景](person-scale-calibration.md) | 用户批准后归档为同组展示v3最佳实践；共同中立参考、网格/墙面尺度证据、等比校准与完整头脚保护，再复用一人一画幅 |
