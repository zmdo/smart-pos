# 报告取景：固定框、保持纸张形状

2026-11-07 用户否决展平效果，当前处理方向改为 **区域筛选 → 裁剪 → 等比放入固定框**。旧展平试验只保留历史记录，不再作为候选生产路径。

1. 使用原始报告素材及既有分类，限定门店目录并核验文件摘要。
2. 视觉模型区分电子截图与纸张照片，定位完整有效正文和主纸张。截图剔除软件 UI 与无用空白，纸张保留可见纸面。
3. 截图只矩形裁剪；纸张使用外接矩形，纸张外多余背景可留白。纸边向外保留余量；纸边与正文框明显冲突时停用蒙版、保留原像素并返回原因。保持纸张本来的形状，不展平、不做透视校正。
4. **固定比例而非像素**：默认 3:4，可通过 `--ratio` 调整。按有效裁剪区域的原始像素构建最小整数比例画布，居中且不重采样；不同原图输出像素可不同，但比例完全相同。HTML 统一等比预览，高清图保留原分辨率。只有明确设置 `--max-side` 才等比缩小导出。完整保留选中区域，必要时留白；不以满铺为理由拉伸或裁掉文字。
5. HTML 显示原图与固定框结果。JSON 返回区域、原文件摘要、统一缩放系数和模型指出的遮挡/缺失；定位失败也保留清单与原因。

入口：[scripts/report_photo_crop](../../scripts/report_photo_crop/README.md)。这是独立预览节点，尚未归档最佳实践、配对训练前后报告或生成最终报告拼贴。正文身份与训练阶段继续由原有报告节点处理，不在这里用外观重新推断。
