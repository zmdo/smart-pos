# 报告取景：原图内的固定比例矩形，核心内容优先

2026-11-07 用户最终规则：取景框是**原图上的矩形**，比例固定、位置和大小可调；框内全部原像素保留。超框时优先保留最主要内容。展平、纸边多边形、抠图和补白画布全部弃用。

1. 复用来源绑定的矩形定位，或识别电子截图正文和实拍纸张外接矩形。限定门店素材并核验原文件摘要，不处理参考模板/说明文件。
2. 在原图内部求默认 3:4 的矩形，优先完整覆盖正文及可用纸面，平移到适当位置；不固定像素尺寸，不越出原图。
3. 原图空间不够时，只对这些受限图片增加核心内容判断：训练报告优先指标名称与训练前后数值；体测报告优先主要身体指标。标题、会员介绍、运动建议及页脚等次要内容可以舍弃。
4. 以核心区域为目标移动原图内的最大同一比例矩形。若仍有核心内容超框，保留候选并明确标记待审核、覆盖率及原因。
5. 直接裁剪矩形内的原始像素。保留框内少量背景和纸张的自然倾斜、弯曲、阴影；不做蒙版、补白或变形。需要限制导出像素时才显式等比缩小。
6. HTML 左边显示原图上的真实取景框，右边显示裁剪结果。绿色表示正文完整，蓝色表示核心内容优先，橙色表示核心仍超框。JSON 返回对应区域、来源、允许舍弃部分和审核说明。

入口：[scripts/report_photo_crop](../../scripts/report_photo_crop/README.md)。已有核心定位也可复用，无需再次调用模型。此节点仍独立于训练前后判断和最终报告拼贴，没有改动已归档成品最佳实践。
