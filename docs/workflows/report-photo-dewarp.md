# 报告照片展平（独立试验，2026-11-07）

目的：为之后的报告原图对比成品，先验证能否修正纸张照片的透视与曲面弯曲。

当前只有 [report_photo_dewarp](../../scripts/report_photo_dewarp/README.md) 模型基线和原图/候选 HTML 对照，未改变已归档的报告表格提取、训练阶段分类、成品生成节点。训练前后顺序不属于这一步。

建议最终节点过程：

1. 复用素材分类与原文件摘要，选择门店报告。
2. 区分电子截图、平整扫描件、透视纸张照片、曲面纸张照片。截图不做曲面变换。
3. 平面透视使用四边几何；曲面照片使用文档展平网格。输出仍由原图像素采样。
4. 校验正文边界、关键数字是否被截掉、横纵表格线是否改善、局部网格是否翻折或过度伸缩；不通过则返回原图及原因。
5. 把通过的图交给后续报告对比排版；绑定原素材 ID、原文件摘要和已有训练阶段，保留回溯关系。

第 2–5 步尚未实现。当前试验有意将截图也送入模型作为负对照：已观察到平整表格被拉弯，以及部分照片顶部标题被额外裁掉，因此不能把模型跑通等同于结果通过。

缺失或被遮住的文字不补画；阴影、折痕的颜色与几何分开评估。首轮只做几何，不做去阴影、锐化或报告文字重绘。
