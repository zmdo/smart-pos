# 会员案例封面

2026-11-06：新增独立封面实验 [scripts/body_scan_cover](../../scripts/body_scan_cover/README.md)，先以 HTML 展示供用户微调，尚不归档为最佳实践，也不改变三视图、各朝向 VS 和单图。

2026-11-07：取景升级为独立的封面双图分支，加入[同组展示最佳实践](../../best-practices/body-scan-group-display-v3/README.md)的 `run_cover.sh`。封面版式仍在实验目录，原三类体测成品不变。

既有阶段结果 → 按素材 ID 选择同会员正面训练前/后 → 生成双图请求 → 封面双图节点复用原图的已确认镜头校正、共同人物尺度及肩部基准 → 只对这两张图求共同有效取景框 → 等比输出封面专用双图 → 封面生成器读取双图、报告及文案 → 1080×1440 封面及 HTML 预览。

该分支从原图一次采样，跳过旧的同组六图共同裁剪与展示版纵向拉伸；不从六图成品反向放大，也不重新估计镜头。原图恢复范围受上游 `source_content_bounds_xyxy` 限制，不得采入黑边或硬拼接的另一张照片。

两张图共用人物尺度单位，求各自有效矩形的共同宽高，默认单张输出 500×478。优先使用同一个肩部相对框；在固定窗口中尽量多展示身体，默认取景高度不超过 2.8 个肩髋长度。允许小量水平移动以利用左右不对称余量，但不以体宽、头宽作为缩放标尺。限制额外顶部留白，避免几何边界的微小倾斜使人物向下偏移。宽高缩放系数必须相同。

如果原图顶部缺失导致“同肩线”和“另一张保留头部”不可同时满足，则共用宽高和缩放，允许垂直取景偏移，并输出独立的 `framing_requires_review` 及原因。原头部缺失不补画；复用的完整度来自旧有效图，不能据此宣称重新检测了原图完整度。原图窄或已经切掉身体时，仍会限制封面能显示的范围。

阶段标签不在封面分支推断。`asset_id`、训练前后、置信度、推断/待审、人审记录全部从原阶段行继承；输出带原审核回传目标。阶段修正后重新生成双图请求，旧阶段版本的双图包会被拒绝。几何/原图摘要也绑定 SHA，修改后不能混用旧包。

三个独立入口及参数见[封面实验说明](../../scripts/body_scan_cover/README.md)：`prepare` 只准备数据；`run_cover.sh` 只产生双图；`body_scan_cover --cover-frames` 只排版。更改标题、故事、教练和地址时可以直接复用双图包，无需重跑前两步。

固定右上“会员案例”；头部缺失不补画，配对缺失不凑图，数字缺失不填示例。报告天数冲突时不渲染具体训练天数。新增模型请求为 0，所有图像处理在远程执行。

用户文字可以通过 `--config` 提供，HTML 编辑区也可以导出同一格式。分别支持主标题、副标题、成果标题、正文及强调片段、教练、地址；优先级为自动值 → 全局默认 → 单会员覆盖。每次生成新目录，回传取景、素材和报告来源以及原有训练阶段的审核目标。
