# 主体定位与大模型兜底（v2.2，2026-11-05）

## 决策与职责

用户确认采用：**先 YOLO 常规定位；失败后再用大模型给主体粗框，交给 YOLO 在区域内重试；最后才使用粗框提示 SAM 2。**

已有大模型分类结果继续负责 `people / kind / background / phase`。YOLO 返回的是位置候选，不将候选框个数直接解释为人数。对比图、非网格图、不确定单人均在定位前跳过。大模型定位结果若与原标签冲突，记录待复核，不强行覆盖分类。

实现文件：`case-studio/tools/subject_localization.py`，由 `grid_rectify_single.py` 调用。定位流程已部署到远程独立网格脚本；网站自动生产管线尚未接入该网格工具。

## 三级路径

### 1. 常规 YOLO

- 按 1024 → 640 → 1280 尺寸尝试；找到可靠候选并通过分割检查即停止。复用同一模型实例。
- 保持原整图置信度阈值 0.35，不全局降低门槛。
- 将明显重叠、横向位置一致的重复框合并为主体范围。重叠门槛 IoU ≥0.55、横向交叠占较窄框宽度 ≥0.85；空间分离的候选不合并。
- 主体尺寸检查、SAM 覆盖检查失败后才进入下一尺寸。常规成功路径不读取 API 凭据，也不调用大模型。
- SAM 掩码只用于排除人体对网格线检测的干扰，不抠图换背景。保留头部贴纸的保守排除区域。

### 2. 大模型粗框 + 区域 YOLO

- 使用现有 `case-studio/settings.json` 的视觉模型配置，每次定位最多新增 **1 个 HTTP 请求**，超时/服务错误进入待复核，不无限重试。
- 提示模型定位网格前的案例主体，忽略海报/照片墙人像，把脸部贴纸计入主体。坐标使用完整解码图像的 0～1 归一化范围，不推测原图外被截断的头脚。
- 返回 `people`、`is_comparison`、`bbox`、`confidence`、`reason`。验证结构、有限数值、坐标顺序、边界、主体大小和确定性；分类冲突或无效粗框不进入裁剪。
- 粗框先向每侧扩展框尺寸的 20%，在该区域尝试 YOLO 640/1024；必要时扩到 40% 再试，总计最多 4 次区域检测。
- 区域内检测阈值为 0.25，并结合粗框交叠与可见身体覆盖筛选。检测框贴近裁图内部边缘则扩大区域重试，避免把截断误当完整定位。
- YOLO 返回坐标先加裁图偏移，映射回原图，再在原图上执行 SAM。最后的图片校正仍使用完整原图。

### 3. 大模型粗框直接提示 SAM

区域 YOLO 仍失败时，以粗框提示 SAM。要求掩码面积、可见范围可信，并拒绝明显扩散到网格背景的掩码；不能把 SAM 不可用时返回的矩形掩码当成此分支的成功证据。失败记录 `subject_localization_unreliable`，保留原图待复核。

## 缓存与可追踪性

有效粗框缓存到 `/root/autodl-fs/case-studio/cache/subject-box/`。键包含解码像素及尺寸、提示词版本、服务地址与模型的指纹；换图、换模型或提示词版本后不复用旧结果。缓存不保存 API Key。

每张 `report.json` 新增 `localization`：

- `attempts`：阶段、推理尺寸、候选框、合并结果、失败原因、裁图范围。
- `route`：`yolo_full` / `yolo_retry` / `vlm_yolo_roi` / `vlm_sam`。
- `selected_box`：最终主体框，原图像素坐标。
- `vlm`：实际新增请求数、缓存是否命中、粗框及提示词版本。

成功定位后增加 `subject_overlay.jpg`，可查看人物框与掩码是否覆盖可见人体。网格残差不达标不会重新触发人物定位请求。
