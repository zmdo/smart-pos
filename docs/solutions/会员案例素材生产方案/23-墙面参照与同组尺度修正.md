# 23. 墙面参照与同组尺度修正

2026-11-05。用户指出g010效果不足，并授权采用更多大模型判断做通用修正。本版不使用会员名、组号或素材ID来决定变换；g010是问题样本，g005/g008为保留效果的回归样本。

用户随后确认本方案为最佳实践，完整权威快照见 [best-practices/body-scan-wall](https://github.com/zmdo/smart-pos/blob/ec5dcb4cda00534b7547dbaaa54177b4d5cfe503/best-practices/body-scan-wall/README.md)，冻结来源为 `c3ce38966da8d39cf702778858e8e5881f9744ff`。本方案文档在快照内也有保留。

## 问题与处理

v2只校正相机侧倾/俯仰，不估计墙面绕竖直轴的方向，g010墙脚线仍明显倾斜。此外，侧面抬臂改变了肩髋距离，单图统一肩髋长度会使该张少放大。新旧关键点相同，问题不来自随机重新检测或最大矩形步骤。

新增模块位于 `scripts/body_scan`：

| 文件 | 职责 |
| --- | --- |
| `reference.py` | 带图像/服务/提示词缓存的场景判断、编号线选择、单图与组图复核 |
| `wall_geometry.py` | SAM排人后的线段检测、几何共识、墙面yaw与质量检查 |
| `group_scale.py` | 墙面SIFT/MAGSAC配准、姿势检查、同组尺度投票 |
| `refinement.py` | 新阶段编排、复用原图关键点、从原图生成成品和保留失败原因 |
| `verify_refinement.py` | 成品几何、保留文件、原图和审查门槛核验 |

### 墙面几何

第一层VLM判断靠墙和平面、指出大致结构区域；第二层在LSD/Hough真实线段上选择编号，避免直接信任模型坐标。可用墙脚线、墙体边缘和真实接缝，不把印刷木纹、文字、斜杆、纸张或空调当墙面参照。

VLM仍可能误选，因此保留长度加权的几何共识：yaw候选差≤2.5°的主簇必须占至少60%支持长度、总长度≥图宽25%。用相机校准重力方向和墙面水平线估计yaw，组合为 `M · K · Y · Rᵀ · K⁻¹`。这是同一相机模型下的重投影，没有直接把横向线剪切拉平。

检查yaw范围2°–30°、参照远离地平线、横线最大残差≤1°且明显改善、竖线不恶化、相对局部各向异性≤1.18、尺度变化≤1.4，以及新增补边≤4个百分点。再比较当前成品与候选做视觉复核。无参照、原本基本水平或任一检查不通过时保留批准的pinhole结果；失败原因写入 `refinement`。

### 同组尺度

场景墙面多边形与SAM人物排除用于特征掩码。双向SIFT匹配、MAGSAC要求至少25个内点、内点率≥50%、特征在横竖两个方向充分分布、p90重投影误差≤2.5px，并限制局部形变。背景配准只用于估计比例，不把人物按背景匹配矩阵直接配准。

只对抬臂/抱臂且明显偏小的照片生成尺度候选。至少两张同组、未抬肩的正背面参考给出的尺度相差≤6%，候选放大幅度在8%–22%内，才继续；这些是通用限制，不是按g010设定固定放大量。姿态判断同时参考VLM与肩肘关键点。

抬臂会抬高真实肩点，因此尺度修正后用髋部和同组中立躯干定位取景；保留真正的肩高差异，仅等比缩放和平移，不局部拉伸身体。报告同时保留测得肩髋与用于取景的中立参照。其他照片仍遵循原肩髋27%、肩部23%规则。最终组图VLM复核可以否决候选。

## 验证与输出

- 40项测试通过，覆盖独立三维墙面构造的横竖/方格度量恢复、语义误选剔除、极端变换拒绝、假参照无像素支持、背景匹配、双参考投票、视觉否决保留旧像素，以及原有27项回归。
- 46张样本仍为41张成品、3张跳过、2张待复核；不重新放行训练图、对比图或上一版失败样本。
- 4张采用墙面修正：`a0101/a0103/a0104`（g010）和 `a0109`（g009），证明新方法不依赖g010分支。
- `a0101` 同时采用背景配准推导的尺度修正，约增加14.4%。两张参考独立支持，组图审查通过。
- 其他37张成品和有效/矩形遮罩与批准v2相同，包括全部12张网格和g005/g008。权威 `best-practices/grid-portrait` 完全未修改。
- 原图SHA、原图关键点、相机矩阵组合、等比取景、锚点策略及有效矩形均单独验证；验证摘要为 `scripts/body_scan/validation-wall-v3.json`。

## 使用入口

从原job一条命令运行：`bash scripts/run_body_scan_refined.sh --job <job.json> --classification-audit <audit.json> --out <新目录>`。基础入口新增 `--refine-background`；旧入口默认行为仍保留。

已有v2结果可运行 `python -m scripts.body_scan.refinement --baseline <v2目录> --out <新目录>`。输入绑定原图SHA，拒绝重复精修或基线变化。具体验证、环境和参数见 [README](../../../scripts/body_scan/README.md)。

几何精度仍受单图焦距/重力估计影响；背景配准近似要求人物贴近墙且同组背景可匹配。纯白墙、参照被遮挡或背景不同的图不会强行修改。VLM是多层证据之一，不能替代可见线段、配准误差、像素回归和人工观感检查。
