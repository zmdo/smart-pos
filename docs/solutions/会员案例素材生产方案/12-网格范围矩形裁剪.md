# 网格范围矩形裁剪（v2.3，2026-11-05）

## 用户确认的取景规则

透视校正后需要输出没有空白角的正规矩形。用户明确允许裁掉部分身体，可以网格范围作为展示范围。因此不再要求整个人体 100% 保留，也不为保住脚部引入大量地板、墙面或空白边角。

默认采用自适应宽高比，优先网格范围，其次人物位置、头部留白与上半身。**不强行拉成 3:4，不再次缩放或拉伸。** 原图和校正全图均保留。当前仍是服务器独立脚本，尚未接入网站自动生产流程。

## 实现

新增 `case-studio/tools/grid_crop.py`，在 `grid_rectify_single.py` 的校正验收成功后执行：

1. 将参与拟合的两组网格线映射到校正图，以两组方向共同覆盖的范围建立网格取景区域，避免邻近海报、门框扩大横向范围。
2. 拟合时会严格筛除轻微弯曲或被人体排除区域遮住的网格片段，**拟合内点的包围框不是网格板完整边界**。裁剪阶段另做较短片段检测：方向和间距相位须与已校正网格一致，横向受已确认网格限制，用于恢复上下端仍然可见的网格。此检测只决定取景范围，不重算校正矩阵。
3. 将原图有效像素掩码映射到校正图。额外识别原图贴边、近乎全黑、占相应边长 1.5%～30% 的黑边；不把内部黑衣服当作无效区域。有效区域向内收 4 像素，避开边缘插值污染。
4. 网格是主要取景框。若头部高于第一条可见网格线，顶部可延伸到人物框上方少量留白；底部不为了脚部额外扩出网格。使用主体 SAM 掩码，不使用海报人物掩码评分。
5. 在候选上下边界之间求共同有效横向范围，并以积分图确认整块矩形都有效，不能只检查四角。评分综合保留区域面积、主体/上半身/头部区段、水平居中与头部留白。允许裁掉肢体，头部和上半身是偏好而非绝对保证。
6. 最终图片仅为校正图的 NumPy 切片。无补边、无内容生成、无二次重采样。坐标映射为 `H_source_to_crop = translation(-left, -top) @ H_source_to_output`。

矩形搜索是有限候选搜索，不保证数学上的最大内接矩形。网格边界和黑边检测为启发式估计；尚未在整批或其他门店素材上全面验收。原照片已经切掉的头脚无法恢复，消除斜边也可能需要少量额外裁切。

## 文件与诊断

每张成功图片新增：

| 文件 / 字段 | 用途 |
|---|---|
| `corrected.png` | 保留原来的完整校正画布 |
| `cropped.png` | 正常展示、下载应使用的纯矩形图片 |
| `crop_preview.jpg` | 左侧校正全图标出绿色裁框，右侧裁后效果，两侧同一显示比例 |
| `report.json` 中的 `presentation_file` | 裁剪成功指向 `cropped.png`，否则保留 `corrected.png` |
| `crop.bounds_xyxy` | 校正图上的裁切坐标，右/下边界不包含在切片内 |
| `crop.grid_bounds_xyxy` | 估计网格范围 |
| `crop.source_content_bounds_xyxy` | 原图去除黑边后的范围 |
| `crop.subject_mask_retained_fraction` | 校正后主体 SAM 掩码的像素保留比例 |
| `crop.upper_subject_mask_retained_fraction` | 主体框上部 60% 区段中的掩码保留比例 |
| `crop.head_band_mask_retained_fraction` | 主体框上部 20% 区段中的掩码保留比例 |
| `crop.valid_fraction` / `resampled` | 成功裁剪必须为 `1.0` / `false` |

上述比例是掩码统计，**不是人体解剖部位的精确识别结果**；贴纸或 SAM 漏分割会影响统计。裁剪没有独立调用大模型。

没有可靠矩形时 `crop.status=needs_review`，记录具体原因。保留已经通过验收的 `corrected.png`，不把裁剪失败误报为网格校正失败，也不覆盖旧实验目录。对比图仍在读取图片、人物推理及裁剪之前跳过。
