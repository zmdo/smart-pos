# 全批人物占画面比例统一（独立方案 v3，2026-11-05）

## 问题与调整

上一版 [肩部对齐加长取景](15-肩部对齐加长取景.md) 已保留并推送，提交 `87009d94826d341bb2dc12acd76df1cdc6552912`。用户再次指出不同图片中的人物占比不一致，并要求以后每轮修改完成后都提交并推送。

根因是旧版只保证**同一组内**的肩髋长度一致。为了不补边、填满 768 × 1792，不同组分别提高缩放：上一版肩髋占画面高度从 29.1% 到 43.2%，最大躯干尺度约为最小的 1.49 倍。单纯统一图片尺寸或加长画框不能解决这个问题。

新入口为 `case-studio/tools/grid_shoulder_frame_uniform.py`，不修改之前三个取景脚本和旧成图。它对**所有会员、所有组和单张组**使用同一套参数：

| 参数 | 默认值 |
|---|---|
| 输出尺寸 | 768 × 1792 |
| 肩髋长度 / 画面高度 | **27%**，即 483.84 像素 |
| 肩部锚点横向位置 | 画面中心 |
| 肩部锚点纵向位置 | 画面高度的 **23%** |
| 像素中心坐标下的共同肩部点 | (383.5, 411.66) |
| 补边颜色 RGB | (238, 234, 227)，可配置 |

27% 的比例给腿部留出了空间。它是构图参数，不是人体解剖比例或医学测量。所有图片按同一个比例执行，原图近景、可用范围不足、某个组成员失败，都不能偷偷改变它。

## “人物占比”的定义

沿用用户之前指定的肩部参照，并使用已验证的肩到髋长度作为人物尺度：正面和背面取两侧肩髋长度的平均值，侧面取已确认可信的一侧。照片都使用既有的姿态结果，不新增检测或大模型判断。

设原校正画布上的肩髋长度为 `L_i`，输出高度为 `H`，比例为 `q`：

```text
共同目标肩髋长度 T = H × q
每张照片的等比缩放 s_i = T / L_i
平移 = 共同肩部输出点 − s_i × 原肩部锚点
最终变换 = 等比缩放平移矩阵 A_i × 原网格校正矩阵
```

不使用发型、头顶、面部贴纸或人物检测框高度作为缩放依据。不强制正侧面具有同样宽度，也不把不同体型变成同样轮廓。真实高低肩、倾斜、胖瘦、衣服和侧身投影仍然保留。

因此“统一”指**人物的显示尺度**，不是将可见人体轮廓的面积强行变得一样。原图只拍了上半身时，缺失的腿不参与猜测；如果为了与全身照拥有相同的可见面积而放大近景，就会重新引入此次要修复的比例差异。

## 用补边代替额外放大

固定尺度、固定长宽比、保留可见腿部、所有原图都无补边，通常不能同时成立。本版优先统一人物尺度，源图不足时添加明确的浅色矩形边距。

1. 复用原网格水平范围，并沿有效像素扩展到网格下方的真实地面。
2. 去除原图明显黑边；原始有效区域内缩 4 像素，避免透视插值接触无效角。
3. 按固定尺度投影有效源矩形，与输出画布求交，只复制该矩形内的真实像素。
4. 四周未覆盖的位置填统一浅色，不复制拉伸人物，不生成背景或身体，不把斜边空洞当成真实内容。
5. 检查参与标定的肩和髋均在保留区域内；否则明确待复核，不能换尺度强行通过。

只从原图一次采样。每张输出附带 `content_mask.png`：255 表示真实图像内容，0 表示补边。报告将 `source_content_fraction` 和 `padding_fraction` 分开，不能把补边统计为真实有效像素。

近景照片会有明显的上下补边，这正好标明缺失范围。输出尺寸和躯干尺度一致，并不意味着每张原图都拍到了完整的人。若不接受补边，则需另选“所有图共同裁成近景”或补拍原图；不能再次按组放大而仍宣称全批尺度统一。
