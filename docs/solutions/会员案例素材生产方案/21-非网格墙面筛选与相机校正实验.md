# 非网格墙面筛选与相机校正实验

用户指出潘艺文第5列（`a0169`）实际为训练照片，并明确体测图必须以墙为背景；同时要求先单独实验非网格几何校正，再考虑整合。

## 已完成

1. 分类提示词升级为 `cls-v3-wall`，加入墙面必要条件、静态展示姿势、训练行为和具体墙面依据；规范化阶段同步约束，旧版本缓存不命中。
2. 新建 `scripts/non_grid_camera`，独立复核素材并测试 GeoCalib 相机侧倾/俯仰重投影、以及叠加径向校正两个候选。主流程 `scripts/body_scan/non_grid.py` 保持恒等变换，网格权威版本未变。
3. GPU推理在单独的远程环境 `/root/apps/non-grid-calibration/.venv` 进行，不在本地推理。源代码在应用目录，权重/缓存/结果在数据盘对应目录。

## 结果与判断

37张复核中，`a0169` 正确改判为 `daily_training`，其余31张非网格候选保留为墙面体测图；另外3张网格与2张对比图作为控制样本。几何阶段跳过训练、网格和对比，共6张；30张各生成两种校正候选，1张 `a0136` 因相机俯仰估计超限待复核。

视觉检查显示木纹墙的透视变化较明显，但所有候选均存在角度或焦距不确定性。海报 `a0034`、白墙 `a0134/a0136` 的两种模型参数明显分歧，不能把径向分支默认当作改善，也不能将“生成候选”称作“校正验收通过”。

这套实验按相机模型处理整张照片，不拟合人体高低肩，不单独压扁/拉长人物，不补造源图之外的内容。只校正侧倾/俯仰及可选径向畸变；墙面的左右朝向尚未恢复，所以不等同于完整墙面正视化。后续需结合可靠墙面结构或标定继续验证，再决定接入方案。

10项实验测试和29项分类/原核心测试通过。原图未修改，60张候选的有效遮罩、矩阵及文件哈希已核对，验证数据随脚本提交。
