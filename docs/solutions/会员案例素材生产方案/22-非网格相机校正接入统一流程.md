# 22. 非网格相机校正接入统一流程

日期：2026-11-05。用户认可上一轮效果后授权第二阶段，将 **pinhole 相机侧倾/俯仰校正**接入 `scripts/body_scan`，随后执行共用人物标准化。radial 仍只保留在独立实验中。

## 流程与边界

墙面体测筛选 → 共用主体框 → 网格/非网格几何分支 → 校正坐标中的肩髋测量 → 统一尺度与肩部锚点 → 最大有效矩形 → 同店同名分组输出。

- 网格继续使用权威双轴校正算法；`best-practices/grid-portrait` 未修改。
- 非网格直接复用 `scripts/non_grid_camera` 中已验证的 GeoCalib pinhole 校准、缓存和画布约束，实验脚本本身未修改。适配器输出 `M · K · Rᵀ · K⁻¹`，不依赖实验导出的图片。
- 肩髋关键点在原图定位，再通过新矩阵映射、校验；按校正后的肩髋长度重算取景，避免继续套用旧版取景比例。
- 取景矩阵与校正矩阵组合，成品从原图采样一次。默认画布768×1792、肩髋长度占27%、肩锚点高度23%，继续尽用原图并保留包含肩髋的最大有效矩形。
- 不确定性提示留档，用户批准 pinhole 版本后不因提示本身拦截。角度、视场角、画布和局部变形的硬限制沿用独立实验。超限/模型失败进入待复核，不自动退回 identity。
- `--non-grid-mode identity` 是显式对照开关；默认 pinhole。网站成品渲染入口仍未接入，本次部署不重启网站。

## 分类与历史数据

入口要求 `wall_background=true`、`body_scan_pose=true`，排除训练活动、镜面/户外以及原有对比/多人/非体测图。缺少新证据的历史标签进入 `wall_classification_refresh_required`。

本批46张通过新的 `cls-v3-wall` 复核：37张复用上一阶段分类缓存，9张网格补充分类。`--classification-audit` 按素材ID、分类版本和原图SHA绑定后合并到内存，不改写原job。部分朝向也随复核更新，故按新标签重新排序；网格像素回归不受影响。

潘艺文训练照 `a0169` 确认为 `daily_training`，不再进入她的成品拼图；`a0168` 原先前面标签更新为背面。本批主体定位未新增大模型粗框请求。验证报告中的 `new_vlm_requests=0` 只指主体定位，分类复核的9次请求单独记录。
