## 4. 降级规则

### 4.1 单图系列（O01/O02/O04/O05/O07/O08）
有 `F-` 就出 O01，有 `F+` 就出 O02。两者无耦合，**各自独立判断**。

### 4.2 VS 系列（O03/O06/O09）
- 前、后都有 → 出 VS。
- 只有其一 → 只出单图，**不出 VS**（避免"用同一张图凑前后"）。
- 前后判别置信度 < 0.7 → 不出 VS，进人工复核。

### 4.3 三视图拼图（O10）
- 6 张齐全 → 出。
- 缺任意一张 → **整张不出**（模板是严格 2×3 网格，留空会显得残缺）。
- 若用户后续补图，重新跑一次即可增量输出。

### 4.4 封面（O11）
- 需 `F-`+`F+`；缺一 → 不出。
- 指标胶囊：优先显示 体重、体脂率、BMI 三项变化；缺某项则该胶囊不渲染（保持 3 栏改为 2 栏/1 栏自适应）。
- 文案：见 `03-数据抽取与文案.md`，无 M 时只保留模板句（不加数字）。

### 4.5 生活照 / 感言 / 训练日常
- `L-`+`L+` 齐 → 出 O12；只有一张 → 出单张（占满一行，不做 VS）。
- `Q` ≥1 → 出 O13；2 张按模板左右排；1 张则居中放大。
- `D` 有 n 张**图片** → 出 n 张（n ≤ 3，超出丢弃多余且记录）。
- **只有 mp4、没有训练照片 → 本期不出 O16**（D12：视频不处理，只登记 `video_deferred`，并在缺口清单里写"该会员只有视频素材，待二期支持"）。

### 4.6 报告类（O14/O15）
- O14 需 `T`（docx/pdf）。无 `T` 但有 `R1/R2` → 不出 O14。
- O15 需 `R1`+`R2`；只有 1 张 → 出单图版（上方单图 + 下方数据表）。
- `T` 缺失时，O15 下半部分的“【身体关键数据变化】表”不渲染，只保留报告照片。

## 5. 输出命名与存储目标

**输入**（用户上传）三种包结构都支持，最终归一为：

```
batch/
  <店名>/
    <会员目录>/          # 原始素材，保持原样
```

**输出根**由存储适配器决定（见 05-§2）：未配置 COS → 本地目录；已配置 → 腾讯云 COS 的 `{prefix}/{batch}/{store}-{member}/`。

```
<输出根>/
  宝安店-曾繁治（输出成品）/
    会员案例封面.jpg
    会员体测正视图（训练前）.jpg
    ...
  _manifest/
    batch-manifest.json
    缺失说明.md
    素材体检.csv
```

- 文件名与模板**逐字一致**（含全角括号、`&`、`VS` 无空格），便于下游直接替换。
- 路径模板可配置：`output.pattern = "{store}-{member}/{output_name}.jpg"`，支持 `{store}/{member}/{output_id}/{date}/{batch}` 占位符；改配置只影响新批次。
- 目录模式：`per_member`（默认，一会员一文件夹）/ `flat`（整店平铺，文件名加会员前缀）。
- 每张成品除文件外，还持有**文字层 JSON 与版本记录**（见 03-§4），重渲染时按 `storage key` **覆盖同名文件**，旧版本存 `versions/v{n}.jpg`。

```markdown
- 已产出：O01 O02 O03 O04 O05 O06 O07 O08 O09 O10 O13 O15（12 张）

  - 会员案例封面 — 依赖 F-/F+ 与指标数据，本次缺指标数据 M（报告缺失）
  - 会员训练日常1..3 — 缺日常训练图
- 需人工确认：
  - 体测侧视图（训练前）phase 置信度 0.62（两张侧视图像差很小）
```

对应机器可读版写进 `batch-manifest.json`：

```json
{
  "member": "陈丽-潘艺文",
  "store": "石厦店",
  "produced": [{"id": "O03", "file": "会员体测正视图（训练前VS训练后）.jpg"}],
  "skipped": [{"id": "O12", "reason": "missing_material", "needs": ["L-", "L+"]}],
  "review": [{"id": "O04", "reason": "low_confidence_phase", "score": 0.62}]
}
```

## 7. 边界情况

| 情况 | 规则 |
| --- | --- |
| 会员目录里混入别的会员照片 | 按人脸聚类拆出，非本人照片不参与成品，记 `foreign_face` |
| 同一会员有多个阶段（>2 次体测） | 本版只取"初始 + 最新阶段"；多阶段另立需求（见 06-Q2） |
| 体测图已带贴纸 | 直接复用，不重复贴（见 01-§6.4） |
| 体测图是横版/非 3:4 | 先按人物居中裁成 3:4，不拉伸；裁切后人物过小则进复核 |
| 会员目录为空 | 不产出，记 `empty_member` |
| 同店不同会员成品目录重名 | 目录名追加序号，manifest 记录映射 |
