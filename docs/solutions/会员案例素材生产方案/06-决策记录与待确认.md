## A. 已确认

### D1 面部贴纸 → 贴纸库

- 贴纸是**库**：可指定、可随机；**一个会员固定一张**（`member.sticker_id`）。
- 未指定时按 `hash(member_id)` 取模随机 → 重跑结果不变。
- 渲染**不缩放**、按入库尺寸原样贴、中心对齐面部框。

### D2 封面文案 → 提示词 + 三层 + 可编辑重渲染

- 成品 = **① 用户照片层 ② 外框层 ③ 文字描述层**。
- 用户写提示词控制文字层；生成后可在界面直接改字，保存即**覆盖重出图**，旧版留档可回滚。
- 数字字段锁定事实：可改措辞，改数字直接被拒。

### D3 输出 → 存储接口化（本地 / 腾讯云 COS）

- 走 `Storage` 接口，本地与 COS 两种实现。

### D4 `A-B` 目录名 = 教练-会员

- 前一个教练、后一个会员；仍用报告文件名/正文交叉校验。

### D5 其余事项按建议执行（见 B 段）

### D6 贴纸生成：一次性 100 张，用完卸载模型

- 允许在本机安装文生图模型，**一次性生成 100 张**同风格贴纸，人工过一遍后直接入库（`source=ai`）。
- 生成完**立即卸载模型权重并释放显存/磁盘**，不常驻、不进线上依赖。
- 100 张足够覆盖现有与未来门店；以后再需要时重启一次生成任务即可。

### D7 COS 暂缓：先跑通本地

- 第一阶段**只实现本地存储**，COS 接口保留但不接；等流程跑通再配桶。
- 因此当前不阻塞于密钥/权限。

### D8 无用户/角色，单一访问令牌

- 站点只有一个 **access token**：输入即用，不做登录、不做角色、不做多租户。
- token 存服务端（0600），前端用 HttpOnly Cookie 维持会话（沿用上一轮 Portrait Studio 的做法）。
- 因为没有角色，**文字编辑不设权限分级**；但每次编辑都记录"时间 + 版本"，可回滚（留痕而不是限权）。

### D9 几何矫正只对"文档类"

- 报告规则已于 2026-11-07 被用户更新：体测报告/训练报告图片只裁剪有效内容并等比放入固定框，禁止展平或透视变形；电子截图剔除 UI，实拍纸张排除外围背景。见[当前工作流](../../workflows/report-photo-crop.md)。原“单应 + 去弯曲”方案已弃用。
- **体测图、生活照、训练照、感言截图 → 只纠正方向，不做透视矫正**（生活照可能故意斜拍，不允许"纠正"构图）。

### D10 去重强制执行

- `sha256` 精确去重 + `pHash` 近似去重，在分类**之前**执行，省 API 额度。
- 前后两张其实是同一张 → 不出 VS，记 `same_image`。

### D11 低质素材：默认丢弃，但可人工覆盖

- 质量评分不达标 → **默认丢弃**（不参与成品），保留原文件与 `drop_reason`。
- 人看到"为什么被丢"后，可以：
  - **强制使用**：照常用，成品打"人工放行"标记；
  - **更换使用**：上传一张新素材替代，新素材同样重新评分（不达标仍然拒绝）。

### D12 MP4 暂不处理

- 本期**不抽帧、不做视频处理**：mp4 只登记元数据，标 `video_deferred`。
- 影响：`会员训练日常` 只在有"训练照片"素材时产出；只有视频则不出。
- 二期再补：抽帧、选帧、去重。

## C. 还需要你/业务方提供

### C1 贴纸验收

- 100 张 AI 贴纸由谁过目（设计/店长）？是否需要"避开某类形象"（比如不要动物、不要食物）？
- 建议：按"卡通扁平 + 头部装饰/遮挡物"的同一风格生成 120 张候选，你挑 100 张入库。

### C2 T2I 模型选型（一次性使用）

- 建议 **SDXL + IP-Adapter**（1024² ≈4 s/张、显存 ~7 GB），120 张约 10 分钟；备选 Flux.1-dev（质量更好，~20 GB 显存）。
- 需要你确认：一次性占用 ~7–25 GB 磁盘可以接受（生成完即删）。

### C3 低质阈值

- 当前阈值是经验值（清晰度 <0.35、人物占比 <3%、短边 <800）。要不要前两批先"只标记不丢弃"，你人工看一轮后再定？
- 建议：**默认丢弃**，但设置里可切成"仅标记"，前两批用后者观察。

### C4 覆盖语义

- 文字改完覆盖同名文件（下游链接不变）。下游 CDN 是否需要刷缓存？必要时可切"改名出新文件"模式。

### C5 历史版本

- 建议每张成品保留最近 5 个版本（`versions/v{n}.jpg`）可回滚。

### C6 二期清单
