## 标准框

**默认输出宽 768 × 高 1280 像素，宽高比 3:5。** 这批网格照片以竖向人体为主，3:5 可以保留较多纵向内容，同时限制两侧背景。尺寸是本次方案的默认选择，并非相机标定标准，可通过参数修改。

需要区分两个尺寸：

| 概念 | 规则 |
|---|---|
| 最终图片 | 所有成功输出严格为同一个宽、高，例如 768 × 1280 |
| 校正图上的取景框 | 统一为 3:5；随原图分辨率和人物尺度调整源像素大小 |

不能直接对不同分辨率原图使用相同像素宽高的裁框，否则 630 像素宽和 1280 像素宽的照片会得到不同的人体占比。也不直接把旧版不同宽高比的裁剪图拉伸到目标尺寸。

## 取景和渲染步骤

1. **只读上一版已通过验收的结果。** 读取 `summary.json`，复用已有分类、主体框、校正矩阵、有效掩码及网格裁剪范围。对比图、非单人网格图仍跳过；旧版未通过校正或裁剪的图片标为待复核。
2. 将原主体框中心通过原校正矩阵映射到校正图，作为目标中心。主体框四角同样映射，用来估计可见人物尺寸。
3. 以人物框高度占标准框高度 **90%** 为初始目标，同时给横向主体框约 **16%** 的总余量。生成目标宽高比的框，优先放在人物中心。
4. 上一版的有效网格裁剪矩形是取景上限。若框超出范围，先缩到能放入的尺寸，再以尽量小的平移量放回有效范围。顶部优先给可见头部保留约框高 **2.5%** 的余量。允许部分身体裁切，不为完整保脚引入无效区域。
5. 因此“居中”是构图目标，不能承诺在所有图上精确居中。靠边、旧图已截断或网格较窄时，优先保证有效画面与可见头部；实际偏移和覆盖比例写入报告。
6. 最终变换只在原校正矩阵上叠加**等比缩放和平移**，没有新增旋转、剪切或横纵不同比例的缩放。矩阵为 `H_source_to_standard = A @ H_source_to_output`，其中 `A` 的横、纵缩放系数相等。
7. 从上一版保存的 `original.png` 一次采样生成结果，避免先校正、再裁剪、再缩放造成重复插值。缩放采用像素中心对齐；源取景框可以有小数坐标，因此非整数比例的目标尺寸也不会引入横纵拉伸。
8. 用有效像素与原图黑边掩码检查整个取景区域，并再次检查目标画布全部有效。失败不补边、不生成缺失身体内容，记录待复核。

标准输出统一了尺寸和比例，**不代表所有人的头顶、脚底、身高或网格物理尺度完全一致**。原图已经截断身体时，人物框只描述可见范围；本方案不是人体测量或前后照片物理尺度标定。

## 输出与诊断

输出目录必须是新目录，不能放进旧实验目录或覆盖已有目录。

| 文件 | 内容 |
|---|---|
| `frame_config.json` | 本次统一宽高及人物占比参数 |
| `summary.json` | 每张图结果、跳过或复核原因 |
| `<id>/standardized.png` | 统一尺寸的成图 |
| `<id>/frame_preview.jpg` | 左侧完整校正图：绿框为旧版范围、蓝框为标准框、红十字为主体中心；右侧为标准成图 |
| `<id>/report.json` | 标准框坐标、映射矩阵、等比缩放系数、居中偏移、主体框保留比例及质量提示 |
| `standard_frames_contact_sheet.jpg` | 所有成功图片按相同显示尺寸排列的总览 |

`center_offset_fraction` 为框中心相对主体中心的偏移，分别除以框宽和框高。`subject_box_retained_fraction` 与 `head_band_box_retained_fraction` 是投影后**检测框多边形**的保留比例，后者取原主体框顶部 20%；不是 SAM 掩码保留比例，也不是独立头部检测。不要与上一版的掩码指标直接比较。

质量提示包括明显偏心、主体/头部区段裁切及源分辨率不足导致的放大。提示不自动拒绝用户已允许的部分身体裁切。新脚本不加载 YOLO/SAM，也不调用大模型或读取 API Key。

## 运行

服务器保留已有 `tools/grid_crop.py`，将新脚本及新入口部署到 `/root/apps/case-studio/` 对应目录即可，无需修改旧脚本或重启网站。

```bash
# 默认 768 × 1280，使用已保存的 v2.3 样本结果
bash /root/apps/case-studio/scripts/remote/run_grid_standard_frame.sh

# 示例：改为 900 × 1500，只处理指定图片
CASE_FRAME_WIDTH=900 CASE_FRAME_HEIGHT=1500 \
  bash /root/apps/case-studio/scripts/remote/run_grid_standard_frame.sh \
  --asset-id a0005 a0008

# 直接运行，可指定不同的已验收实验目录
/root/apps/portrait-studio/.venv/bin/python \
  /root/apps/case-studio/tools/grid_standard_frame.py \
  --input /absolute/saved-grid-experiment \
  --out /absolute/new-standard-frame-experiment \
  --width 768 --height 1280 --subject-fill 0.90
```

宽高分别支持 64～4096 像素，宽高比支持 1:2～1:1；人物目标占比支持 0.60～0.98。增加目标占比会倾向于更紧的取景，实际取景仍受原图和网格范围限制。
