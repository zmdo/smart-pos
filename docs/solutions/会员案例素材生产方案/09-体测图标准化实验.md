# 09 · 体测图标准化实验（对比图 → 单张标准图）

> 目标：不按"对半切"，而是**先把每个人从对比图里独立出来**，再按统一机位重排成标准单图。
> 脚本：`case-studio/tools/standardize_pair_v4.py`（服务器 `/root/apps/case-studio/tools/`）

## 1. 按需求实现的四步

| 步 | 实现 | 参数（可配） |
| --- | --- | --- |
| ① 单张标准尺寸 | 画布 1080×1440（3:4），sRGB，JPEG q92 | `--canvas 1080x1440` |
| ② 框选人物 | YOLO11n 出框 → SAM 2.1（box prompt）出掩码 | 置信度 0.35 |
| ③ 以人物为中心外扩 | 人物高度占画布 86%，脚底线固定在画布 94%，水平按人物中心对齐；两张用同一套规则 → 尺寸/机位一致 | `PERSON_FRAC=0.86`、`FEET_Y=0.94` |
| ④ AI 补全越界 | 估计墙面网格周期/相位 → 按周期平移**真实像素**补洞（不回卷）→ 残余用 inpaint 收尾；同时用 Depth-Anything 估计两人物深度差，判断机位是否一致 | `period_fft`、`fill_no_wrap` |
| ⑤ 大模型查错位 | DeepSeek-V4.1 双图对比，输出 `edge_misalign / person_cut / obvious_paste / camera_consistency / score` | 关闭开关 `--no-vlm` |

## 2. 实验过程与结论（同一张：景田店·董彦琦 侧视对比图）

| 版本 | 补全方式 | VLM 分 | 主要问题 |
| --- | --- | --- | --- |
| v1 | 直接镜像 | 25 | 把隔壁那个人镜像进来了；网格断裂；脚被切 |
| v3 | 周期平移（np.roll） | 25 | 回卷把对侧内容卷进来，出现重复纹带 |
| v4/v6 | 无回卷平移 + 邻人区域剔除 | 35 | 网格基本连续，但手臂周围仍有重复色块/断裂 |
| v7 | 再加"中缝带不取样" | 35 | 左侧补全区出现拖影 |

**关键发现**：这张"对比图"的左右两半**本来就是两张独立拍摄的照片**（VLM 甚至判断"图1 侧身正面、图2 侧身背面"）。所以：

1. "对半切"从根上是错的 —— 不是一张连续场景被切开，而是两张照片被拼在一起；
2. 任何"接缝补全"都救不了，因为两边的**背景透视/光照/网格相位**本来就不一致；
3. 正确路线是：**人物抠出来 → 背景整套重建（或生成式重绘）→ 按统一机位合成**，而不是补缝。

## 3. 当前方案（v9 修正版）：中线分界 + 共用缩放

| 步 | 做法 | 关键点 |
| --- | --- | --- |
| ① YOLO 出框 | 取最左/最右两人 | — |
| ② 分界 | **两人之间的中线** | 不能用"隔壁人物左边界"：合成图的拼接缝在更内侧，会把另一张照片的边缘条带进来（v9 的错位就是这个） |
| ③ 统一取景 | **一对图共用一个缩放比例**（frac 取两人里最"挤"的那个），画布 960×1920（1:2） | 之前按人各算 frac（1.884 vs 1.824），左边被多放大 3.3% → "左边大一圈" |
| ④ 保留原背景 | 不抠图、不补全 | — |
| ⑤ 调色调 | LAB 均值/方差匹配（强度 0.7） | — |
| ⑥ 质检 | 人物完整 / 留白 / 邻居露入面积 / 两张尺度差 | — |

实测（董彦琦 侧视）：
- 人物像素高度 BEFORE 1403px、AFTER 1412px（差 0.6%，在 YOLO 框噪声内）；
- 宽度 747 vs 649（差 15%）—— 这是真实的减脂变化，不是缩放；
- `neighbor_area_pct = 0`，边缘无拼接残条。
