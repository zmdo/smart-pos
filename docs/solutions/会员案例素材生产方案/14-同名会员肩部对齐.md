## 对齐什么

用户指出：同为 768 × 1280，人物的实际显示大小仍不一致；头部贴纸和发型会干扰以头部为参照的标定。

本方案对同一门店、同名会员的多张照片，同时统一：

1. **肩部锚点位置**：正面、背面取双肩关键点的中点；侧面取可信度更高的可见侧肩关节。
2. **躯干尺度**：按同侧肩关节到髋关节的距离等比缩放。正面/背面取两侧长度的平均值，侧面取同一个可信侧的肩髋长度。
3. **成图尺寸**：仍为统一的 **768 × 1280**，可配置。

头部、鼻子、眼睛、发型、脸部贴纸不参与锚点或尺度计算。**不使用肩宽统一缩放**，否则侧面两肩投影接近时会被错误放大。

这里对齐的是肩部锚点，不是把两侧肩膀强行拉平。只追加等比缩放和平移，不旋转身体、不剪切、不改变横纵比例；保留真实高低肩、身体倾斜和原有网格校正。也不强制统一肩宽、腰宽。

## 肩部与髋部检测

使用 GPU 上的 `YOLO11m-pose`。COCO 关键点索引：5/6 为左右肩，11/12 为左右髋。模型及关键点接口见 [Ultralytics 姿态估计说明](https://docs.ultralytics.com/tasks/pose/) 与 [YOLO11 模型说明](https://docs.ultralytics.com/models/yolo11/)。

本批预检发现 640 推理尺寸比 1024 更稳定，因此正式路径为：

1. 原图 640 尺寸姿态检测。
2. 既有人物框向四周扩 20% 的区域，以 640 尺寸检测；区域坐标必须先映射回完整原图。
3. 两个不同上下文中的肩部位置、肩髋长度相符才通过；否则尝试区域 1024、整图 1024，最多 4 次推理。

候选必须匹配已有主体框：IoU 至少 0.35、交集占较小框面积至少 0.65。关键点置信度至少 0.60，并通过点位边界、肩在髋上方、躯干长度范围、两侧长度一致性等检查。正面和背面需要两组肩髋点；侧面选择更可信的一组，不用低置信度的遮挡侧硬凑双肩。

跨上下文的肩髋长度差不超过较短长度的 12%，肩部锚点偏移不超过较短长度的 10%。通过后选择有另一上下文支持的高质量候选。失败不退回头部标定，不猜测坐标，记录 `shoulder_pose_not_reliable_across_contexts`。

成功结果缓存在 `/root/autodl-fs/case-studio/cache/shoulder-pose/`。缓存键包含图像像素、主体框、原校正矩阵、朝向、算法版本和权重 SHA256；缓存命中后重新计算关键点几何。新流程不读取 API Key，也不调用大模型 API。

置信度和双次一致性不等于人工真值，仍需结合 `pose_overlay.jpg` 检查。侧身遮挡、宽松衣物、弯腰和真实姿态变化可能影响二维肩髋长度。

## 整组求解取景框

每张图的肩髋长度为 `L_i`，整组共同目标长度为 `T`，则缩放为 `s_i = T / L_i`。共同肩部输出位置为 `(X, Y)`，每张仅按自己的肩部坐标计算平移。

默认 `T` 从画面高度的 36% 开始。取景上限采用上一版无空白角的网格裁剪范围，并额外留 2 像素内边距。**先求所有图片都能容纳的共同尺度和共同锚点，再分别渲染**，不能渲染时逐张独立移动肩线。

- 水平方向肩部锚点精确落在画面中心。
- 如果原始取景太紧，整组一起提高目标躯干尺度，以满足有效像素约束；允许相应裁掉部分身体。所需躯干长度超过画面高度 75% 时整组待复核，避免极端放大。
- 默认在共同可行区间内尽量保留已有的上方画面，肩部优先不低于画面中线。此规则使用网格有效范围，不使用头顶或发型来标定尺度。
- 可指定 `--shoulder-y` 作为偏好的肩线相对高度；边界不足时整组共同调整，并记录提示。
- 同组肩部位置一致，但不同会员组可以有不同的肩线高度；例如某组原图本来缺少头部区域，就不能与完整全身组强行共用同一高度而又不补空白。
- 合成矩阵为 `H_source_to_aligned = A_i @ H_source_to_output`，`A_i` 仅含正的等比缩放和平移。从保存的原图一次采样，保持原透视校正不变。

输出前检查整个裁框和输出有效掩码，确保没有无效角。裁框不会补造头脚或背景。照片本身缺失的内容无法恢复。

若组内有检测失败图片，`groups.json` 会列出 `requested_asset_ids`、`excluded_asset_ids`、实际输出及 `complete=false`。不能把其余图片成功误报为整组已完成。

## 输出文件

| 文件 | 用途 |
|---|---|
| `<id>/aligned.png` | 768 × 1280 的干净成图，无诊断点线 |
| `<id>/alignment_guide.jpg` | 同尺寸诊断图：红点为选用的肩关节，绿点为髋关节，黄十字为肩部锚点，青线为共同肩线 |
| `<id>/pose_overlay.jpg` | 完整校正图上的关键点及最终裁框，便于排查定位问题 |
| `<id>/report.json` | 姿态重试、置信度、缓存、原坐标/校正坐标、最终矩阵、锚点位置及尺度 |
| `groups.json` | 分组、共同肩部位置、共同躯干尺度、排除图片与完成状态 |
| `groups/<group>/aligned_group.jpg` | 组内肩部对齐总览 |
| `groups/<group>/comparison.jpg` | 上排为旧标准框，下排为新方案诊断图；这是算法版本对照，不是训练前后顺序 |
| `shoulder_groups_contact_sheet.jpg` | 按会员分组的全部结果 |

`subject_box_retained_fraction` 是主体检测框投影面积的保留比例，不是人体掩码保留比例。本方案用于构图归一化，不是经过相机标定的身高、肩宽或体态医学测量。
