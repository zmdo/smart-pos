# 共用体测图处理与非网格基线

用户本轮授权实现代码：从权威最佳实践复制到 `scripts` 并整理共用流程，加入非网格体测图；非网格背景几何变换函数默认不处理，先查看共用取景效果。

## 实现范围

新入口为 `scripts/run_body_scan.sh` / `python -m scripts.body_scan`。实现位于 `scripts/body_scan/`，与冻结的 `best-practices/grid-portrait/` 和旧 `case-studio/tools/` 独立。复制来源、函数及哈希记录在 `provenance.json`；冻结目录的 12 个文件哈希全部保持一致。

输入为现有上游分类后的 `job.json` 与原图：先过滤非体测/对比/多人素材，复用原有大模型标签；再执行共用主体定位，按背景选择几何矩阵，接着共用肩髋定位、统一比例与肩部位置、全原图有效区域合成及最大矩形取景。没有新增一套分类流程，也不再依赖之前各版本实验的中间文件。

- 网格：保留双轴网格约束、方格比例、人物遮挡排除和输出残差检查。
- 非网格：`normal_transform()` 只返回 `np.eye(3)`；没有旋转、透视、镜头去畸变或背景补画。
- 共用：默认 768×1792，肩髋长度为高度 27%，肩部锚点位于水平中心和高度 23%。合并几何变换及缩放平移，成品从原图采样一次。真实有效照片区域为最大矩形，矩形之外保持浅色画布。
- 同名按门店分组，前/后/左/右排序。保留原图、成品、源有效遮罩、实际采用遮罩、检测/矩阵报告、分组预览、拼图和 ZIP。失败图明确列为待复核。

因此，非网格成品仍会发生等比缩放、平移和裁剪；“不处理”指的是背景几何修正阶段。原来倾斜的背景仍然倾斜。缺失的头/腿不会生成或补齐，画布不会为某张图片单独改变比例。

## 后续边界

本轮未实现非网格真实扶正，也未接入网站成品渲染。后续只需在 `non_grid.py` 扩展几何估计并返回矩阵，公共主体定位与取景流程无需再复制。分类标签仍来自既有缓存；朝向/背景标签若需修正，应由上游分类或人工复核处理，不能用图中检测框数量代替人数标签。
