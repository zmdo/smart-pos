# 按会员并行预处理

2026-11-07。先停止正在处理的景田店批次，保留完成节点；验证并部署新工作流后再恢复。

## 调度与隔离

批次只统一解包。之后以“门店/会员目录”为边界，默认同时推进 2 位会员。每位会员有独立的素材清单、节点输出、进度和重试记录；同一人的照片保持完整一组。内部子任务不出现在历史记录。

会员内分为体测处理、报告处理、其他成品三条独立分支。训练前后判断等待标准化与报告结果，随后汇总审核数据。全局 GPU 通道为 1、CPU 成品通道为 2，模型请求最多 3 个并发；模型请求通过仅监听本机的鉴权转发器统一限流，冻结最佳实践文件不修改。

旧批次已完成的解包、分类和拆分结果按会员筛选后复用；未完成节点使用新目录。所有资产保留原 ID、原图 SHA 与来源关系。子任务完成后，合并媒体授权与审核记录，使用稳定的会员 ID，避免跨会员引用。

单个会员失败不影响其他会员继续；批次重试只执行未完成会员与节点。服务停止会终止已启动子进程组，等待资源的步骤收到停止信号，重启后保留可重试状态。

## 页面

预处理页使用三个列表展示“正在并行预处理”“已完成预处理”“排队中”，每项包含门店、教练/会员名、图片数、当前步骤和进度。等待 GPU/CPU 通道明确显示等待原因。失败会员单独列出原因，避免混入排队。页面定时刷新；全部完成后进入原人工审核页面。

## 验收范围

测试会员隔离、并发上限、节点更新无丢失、失败后其他会员继续、重试复用、媒体合并、模型代理鉴权与全局限流；远程真实素材验证并在浏览器检查列表动态变化。运行中的生产任务不用于测试注入故障。部署完成后恢复原景田店批次，记录实际结果。
