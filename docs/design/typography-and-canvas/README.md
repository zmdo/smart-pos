# 字体、生活照遮挡与统一画布

2026-11-08。在现有审核/生成流程增加字体库、逐项字体选择、生活照独立遮挡开关，以及除生活照外统一 3:4 输出。

## 数据与界面

- 字体库提供字体样张、TTF/OTF 上传及停用。字体二进制按内容摘要保存，停用不删除历史引用。预置思源黑体、思源宋体与两种开源展示字体，许可随库提供。
- 设置页提供全局默认字体、各默认文案字体、统一输出宽度与背景色、生活照遮挡（默认关闭）。高度由宽度按 4/3 计算。
- 审核中的程序绘制文字逐项选择字体；未指定的项跟随全局。包括封面、对比图、表格标题/表头/单元格、单图说明及感言标题/品牌。截图、照片或 Logo 内已有文字不重建。
- 成品设置在下一次预览或生成时生效，开始渲染时冻结设置，避免同批处理中途变更。字体与画布信息加入缓存指纹；既有正式版本不覆盖。

## 几何与隐私

- 全部照片等比缩放；单图、六图、训练照整体居中补背景。封面仍按独立取景框构图。
- 同朝向对比图固定画布，页眉/页脚留出空间后，Before+After 使用共同高度组成无缝照片对，整体居中放入剩余区域；只在组合外补背景。
- 报告图在固定 3:4 画布中重新排布；缺少原报告时表格填满内容区。
- 感言复用审核过的截图布局与隐私遮盖，重新绘制文字区以支持字体选择。
- 生活照遮挡关闭时不参与头像检查，也不调用头像覆盖；保持原文件与尺寸。开启时沿用会员头像及原有检查规则；已存在的照片贴纸不反向去除。
