# 实现与验收

## 实现

- `case-studio/studio/avatar_api.py`：Qwen Image 2.1 Pro 异步生图，正面参考图 + Memoji 风格提示词。检查实际 RGBA 通道、清除 alpha 噪声；拒绝仅白底或假透明结果。没有本地扩散模型或新增 GPU 显存需求。
- API 任务 ID、请求摘要与结果保存在网站数据目录；文件锁防止重复提交，同一请求复用缓存。超时可继续查询，包括主动重新生成的任务；提交结果不明时要求主动重试，避免自动重复计费。结果存储地址下载不携带 API Key。
- `privacy.py`：独立逐脸检查、会员固定贴纸、原图摘要绑定和输出副本。口罩、墨镜、侧脸不作为完整卡通遮挡。面部证据不可靠时记录原因，未检查素材不得输出为已遮挡照片；生图失败使用标准头像并显示原因。
- 审核顶部可开关遮挡、选择 AI / 图库随机、重新生成或手动选图。切换后新增审核版本并使对比图/封面缓存失效。后台准备不覆盖期间发生的人工编辑。
- 新预处理增加独立隐私节点，按原有会员并行工作流执行。既有体态、缩放、取景和阶段分析继续使用原图；最终三视图、对比图、朝向单图、封面、训练/生活照读取遮挡副本。
- `assets/stickers` 预置 100 张透明 PNG：97 张 Twemoji 表情/动物 + 男、女、中性三个标准 AI 头像。按性别或通用标签匹配。Twemoji 固定上游提交 `b6b55fef1e8636b540a6d016a4729ca8cdf2e60b`，保留 CC BY 4.0 授权和来源；使用遮挡的会员 ZIP 包附素材说明。维护脚本 `scripts/build_sticker_library.py` 需要额外的 `cairosvg`，网站运行直接使用打包 PNG。
- 设置提供独立生图接口与 Key；默认复用同域视觉模型 Key。API 不向浏览器返回 Key。导航新增「贴纸库」，支持名称/标签搜索和性别筛选。

## 验证

2026-11-08，在服务器隔离命名空间 `face-privacy-qa` 验收，不修改正式会员记录。

- 后端 82 项测试；前端三个测试文件包含 13 项下载、缓存、轮询行为检查。
- 使用关文博、唐怡婷现有数据：前者保留已有 8 处贴纸、补遮 1 处侧脸，因无可靠无遮挡正面照使用标准男性头像；后者根据正面参考图真实调用 API 生成头像，覆盖 7 处可见面部（含标准照片、封面来源和生活照）。
- 完整生成 28 张成品，核验 ZIP 完整性、分组目录、审核信息和贴纸出处。所有 100 张图库 PNG 均有有效透明通道；源照片 SHA、训练阶段标记与会员信息保持一致。
- 浏览器验证默认 AI、后台准备、正面参考头像、图库随机、手动选择、设置面板与 100 张图库加载；检查了实际封面和训练照的遮挡效果。
- 代表性接口、ZIP 与原图摘要结果位于服务器 `face-privacy-qa/validation.json`；测试日志位于 `experiments/face-privacy-tests.log`。本机验收图片位于项目上级 `artifacts/member-face-privacy/`。

## 历史与恢复

旧审核记录不会被批量改写，旧成品可继续查看。需要遮挡时，在审核顶部准备贴纸并重新生成成品。人工审核用的源素材仍可查看原图；遮挡应用于成品预览和下载。视觉模型的面部检查仍有误判可能，应查看生成的效果图。

部署前备份应用代码与 SQLite 快照；备份路径写入服务器 `website/face-privacy-deployment.json`。回滚仅恢复代码，保留数据目录、审核快照、原图与既有成品，不覆盖用户后续编辑。

## 头像尺寸调整（2026-11-08）

旧实现先将面部框放大到 1.55 倍，再按头像比例铺满；窄脸与侧脸的横向放大尤其明显。新版 `face-overlay-compact-v2.2` 使用 1.16 倍等比贴纸，宽高较旧版约减少 25%。底层只覆盖略有余量的脸部椭圆，先将区域降采样为 3×3 再放大，消除透明边缘下的五官细节，避免为了盖住矩形四角而继续放大头像，也避免出现明显的纯色色块。

检测证据与贴纸 ID 保持不变，不重新调用视觉模型或生图 API。遮挡副本、对比图和封面预览都加入独立绘制版本作为缓存键；报告缓存不受影响。旧成品版本保留，新预览和新成品采用小头像。

远程 85 项后端测试通过，新增脸部椭圆覆盖、等比缩小幅度、绘制缓存失效且检测证据复用检查。用现有正面、侧面、训练照、生活照与封面做实际验收，结果位于 `face-privacy-qa/compact-validated/`，本机副本在 `artifacts/member-face-privacy/compact-validated/`。
