# 实现与验收

## 实现

- `case-studio/studio/avatar_api.py`：Qwen Image 2.1 Pro 异步生图，正面参考图 + Memoji 风格提示词。检查实际 RGBA 通道、清除 alpha 噪声；拒绝仅白底或假透明结果。没有本地扩散模型或新增 GPU 显存需求。
- API 任务 ID、请求摘要与结果保存在网站数据目录；文件锁防止重复提交，同一请求复用缓存。超时可继续查询，包括主动重新生成的任务；提交结果不明时要求主动重试，避免自动重复计费。结果存储地址下载不携带 API Key。
- `privacy.py`：独立逐脸检查、会员固定贴纸、原图摘要绑定和输出副本。口罩、墨镜、侧脸不作为完整卡通遮挡。面部证据不可靠时记录原因，未检查素材不得输出为已遮挡照片；生图失败使用标准头像并显示原因。
- 审核顶部可开关遮挡、选择 AI / 图库随机、重新生成或手动选图。切换后新增审核版本并使对比图/封面缓存失效。后台准备不覆盖期间发生的人工编辑。
- 新预处理增加独立隐私节点，按原有会员并行工作流执行。既有体态、缩放、取景和阶段分析继续使用原图；最终三视图、对比图、朝向单图、封面、训练/生活照读取遮挡副本。
- `assets/stickers` 预置 100 张透明 PNG：97 张 Twemoji 表情/动物 + 男、女、中性三个标准 AI 头像。按性别或通用标签匹配。Twemoji 固定上游提交 `b6b55fef1e8636b540a6d016a4729ca8cdf2e60b`，保留 CC BY 4.0 授权和来源；使用遮挡的会员 ZIP 包附素材说明。维护脚本 `scripts/build_sticker_library.py` 需要额外的 `cairosvg`，网站运行直接使用打包 PNG。
- 设置提供独立生图接口与 Key；默认复用同域视觉模型 Key。API 不向浏览器返回 Key。导航新增「贴纸库」，支持名称/标签搜索和性别筛选。

## 验证

2026-11-08，在服务器隔离命名空间 `face-privacy-qa` 验收，不修改正式会员记录。

- 后端 82 项测试；前端三个测试文件包含 13 项下载、缓存、轮询行为检查。
- 使用关文博、唐怡婷现有数据：前者保留已有 8 处贴纸、补遮 1 处侧脸，因无可靠无遮挡正面照使用标准男性头像；后者根据正面参考图真实调用 API 生成头像，覆盖 7 处可见面部（含标准照片、封面来源和生活照）。
- 完整生成 28 张成品，核验 ZIP 完整性、分组目录、审核信息和贴纸出处。所有 100 张图库 PNG 均有有效透明通道；源照片 SHA、训练阶段标记与会员信息保持一致。
- 浏览器验证默认 AI、后台准备、正面参考头像、图库随机、手动选择、设置面板与 100 张图库加载；检查了实际封面和训练照的遮挡效果。
- 代表性接口、ZIP 与原图摘要结果位于服务器 `face-privacy-qa/validation.json`；测试日志位于 `experiments/face-privacy-tests.log`。本机验收图片位于项目上级 `artifacts/member-face-privacy/`。

## 历史与恢复

旧审核记录不会被批量改写，旧成品可继续查看。需要遮挡时，在审核顶部准备贴纸并重新生成成品。人工审核用的源素材仍可查看原图；遮挡应用于成品预览和下载。视觉模型的面部检查仍有误判可能，应查看生成的效果图。

部署前备份应用代码与 SQLite 快照；备份路径写入服务器 `website/face-privacy-deployment.json`。回滚仅恢复代码，保留数据目录、审核快照、原图与既有成品，不覆盖用户后续编辑。

## 头像尺寸调整（2026-11-08）

旧实现先将面部框放大到 1.55 倍，再按头像比例铺满；窄脸与侧脸的横向放大尤其明显。新版 `face-overlay-compact-v2.2` 使用 1.16 倍等比贴纸，宽高较旧版约减少 25%。底层只覆盖略有余量的脸部椭圆，先将区域降采样为 3×3 再放大，消除透明边缘下的五官细节，避免为了盖住矩形四角而继续放大头像，也避免出现明显的纯色色块。

检测证据与贴纸 ID 保持不变，不重新调用视觉模型或生图 API。遮挡副本、对比图和封面预览都加入独立绘制版本作为缓存键；报告缓存不受影响。旧成品版本保留，新预览和新成品采用小头像。

远程 85 项后端测试通过，新增脸部椭圆覆盖、等比缩小幅度、绘制缓存失效且检测证据复用检查。用现有正面、侧面、训练照、生活照与封面做实际验收，结果位于 `face-privacy-qa/compact-validated/`，本机副本在 `artifacts/member-face-privacy/compact-validated/`。

## 成品内头像尺寸与头身衔接（2026-11-08）

`face-overlay-body-anchor-v5` 增加独立 `studio/privacy_panels.py`。先完成照片的最终取景/缩放，再用同一变换矩阵投影面部框，在封面、同朝向对比图或六图拼图内使用相同像素宽高的头像，保持等比。贴图后拼接不再改变头像尺寸。

完整头像包含头发，检测框只包含额头到下巴，所以按框中心贴图会压低下巴。新版使用每张照片自己的头部和下颌作为定位基准：正面优先双耳中点，其次双眼中点；侧面优先高置信度可见耳，避免面部框中心偏向鼻子。纵向让头像下缘贴近实际下颌，保留 4% 面部高度的覆盖余量。人物本身的姿态和坐标保持不变，不强制把不同照片的头像移到同一个画布坐标。

关键点复用上游检测结果，先核对源图 SHA，再经对应的显示/等比图/封面矩阵映射到最终照片格子。可信度不足或关键点远离面部时退回该图的面部框。边缘空间不足时全组等比缩小至可用范围，最多缩小 15%；仍放不下则提示扩大取景，避免把头像往下推而遮住脖子。已有贴纸、背面和画面外人脸不参与统一尺寸；背景小人脸独立遮挡。

底层遮挡保留在实际面部位置，仍使用 3×3 降采样和不透明椭圆。`privacy_layout` 记录统一尺寸、面部框、头像坐标、头部锚点和锚点来源。分区预览、完整预览和遮挡副本均包含绘制版本，旧历史成品保留。AI 头像、面部证据、阶段标签与原图复用，新增模型调用为零；冻结的最佳实践绘制文件没有改动。

验证：远程 100 项后端测试通过，覆盖不同缩放下的相同头像像素尺寸、各自下颌衔接、耳部定位、无效关键点回退、边缘统一缩小、六图独立定位、已有贴纸保留、背景脸独立尺寸和隐私证据检查。周俊仿正面对比图两侧头像均为 168×205 px、侧面对比图均为 199×243 px、封面均为 159×193 px。唐怡婷完整生成 13 张成品，六图拼图四个可见面部均使用 277×329 px 头像，背面保持原状。实际检查正面、侧面、六图与封面的头颈衔接。

验收文件：服务器 `experiments/body-anchor-v5/m002/`、`face-privacy-qa/body-anchor-v5/m009-full/`；日志 `experiments/face-privacy-body-anchor-tests.log`。本机示例为 `artifacts/member-face-privacy/body-anchor-v5/`。

本次部署与备份路径记录在 `website/shared-avatar-deployment.json`。恢复旧代码时使用该备份，保留审核、原图与成品历史。

## 装饰表情头像与背向遮挡（2026-11-08）

- `avatar_api.build_prompt` 根据会员性别配置帽饰或蝴蝶结/耳饰，加入自然的眉眼与笑容；按生成标识稳定选择风格，重试不会随机更换提示词。参考图限制到下巴附近，额外保留头发区域；仅生成透明悬浮头像，装饰不应延伸成大帽檐或长挂饰。
- 新标准头像使用独立 `*-expressive-v2` ID。旧标准文件与 ID 保留，但从当前图库列表和随机候选中退役；当前可选贴纸仍为 100 张。`build_sticker_library.py --avatars-only` 可单独维护标准头像，不重新下载表情素材。
- 面部检查结果的 `hidden`（有可定位头部但五官不可见，包括后脑）纳入遮挡。独立 `SCAN_VERSION` 升级检查缓存，新提示词明确背向头部不得因没有五官而漏报。已绑定 SHA 的单人体测/封面头部证据可复用；训练和生活照的旧检查在准备时升级。
- 六图拼图的后脑参与同组头像尺寸统一，后脑横向定位优先双耳中点；对比图、单图、训练/生活照也覆盖已定位后脑。旧背向图若没有头部范围，绘图会要求重新检查；已完成新版检查且头部完全出画的素材可正常跳过。
- 审核入口改为“头部隐私保护”，明确包含背向，并分别显示面部与后脑/隐藏面部计数。预览缓存使用 `head-overlay-expressive-v6`；已有卡通遮挡、训练阶段和原始文件保留。

验证：108 项后端测试和 13 项前端行为检查通过。通过真实 Qwen API 生成三张新标准头像，以及唐怡婷、周俊仿的带装饰专属头像；检查真实透明通道与头颈衔接，拒用带脖子的候选。两名会员完整生成 25 张成品，唐怡婷的六图中六个头部均已遮挡，背面对比图两侧也已遮挡；周俊仿的背向单图已遮挡。原图与审核阶段数据不变，缺少后期背面配对时仍如实记录缺项。

验收产物位于服务器 `face-privacy-qa/expressive-v6/`，本机 `artifacts/member-face-privacy/expressive-v6/`；测试日志为 `experiments/face-privacy-expressive-tests.log`。部署记录与备份路径为 `website/expressive-heads-deployment.json`。恢复旧代码时保留新增头像与贴纸目录数据，避免后续审核引用失效。

## 仅贴纸遮挡（2026-11-08）

按最新展示要求移除旧版 3×3 模糊椭圆底板。`privacy.overlay`（独立照片）与 `privacy_panels.mask_panels`（封面、对比、拼图和朝向单图）只做透明头像的 alpha 合成，透明区域保留原图，允许少量边缘露出。头像的统一尺寸、头颈锚点、装饰表情和背向遮挡规则保持不变；不重新生成头像或检测人物。上述历史章节中的椭圆补遮罩不再使用。

绘制版本更新为 `head-overlay-sticker-only-v7`，使遮挡副本、分区预览和完整预览重新生成。旧成品版本保留，报告和人工审核内容不变。回归检查覆盖透明像素不附加底板、单图与拼图的透明孔洞保留原图纹理、背向头部继续贴图，以及原有尺寸、定位和缓存规则。

验证：110 项后端测试通过。复用唐怡婷、周俊仿原有头像与检测证据生成 25 张成品，逐项核对输出数量、尺寸与 19 组成品的头像布局完全一致；可见脸和背向头部只叠加贴纸。验收产物位于服务器 `face-privacy-qa/sticker-only-v7/`，本机 `artifacts/member-face-privacy/sticker-only-v7/`；测试日志为 `experiments/face-privacy-sticker-only-tests.log`。部署备份与验证记录为 `website/sticker-only-deployment.json`。
