# 会员面部遮挡与 API 头像

2026-11-08，分支 `feat/person-face-masking`。

## 规则

- 默认开启，默认 AI 头像。使用 Qwen Image 2.1 Pro 的异步 API，明确要求 Memoji 风格、透明 RGBA、仅头部；女士使用蝴蝶结/耳饰与可爱温柔的表情，男士使用小巧帽饰与帅气自然的表情；不在 GPU 服务器加载生图模型。
- 每位会员固定一张贴纸。正面无遮挡照片可作为参考；没有可靠正面参考时使用预先生成的标准男/女头像，性别未设置用中性头像。人工选择或重新生成前保持不变。
- 贴纸库预置约 100 张有标签的贴纸，包含透明 AI 头像及开源表情/动物。随机选择匹配已确认性别或通用标签；记录出处和授权。
- 已有卡通贴纸/表情包且完整覆盖面部的区域保留；口罩、墨镜、手、头发遮脸不等同完整卡通遮挡。正面、侧脸、多人和镜中人脸均检查，背面后脑同样遮挡，沿用该会员的固定贴纸。
- 体测图、封面、训练照、生活照使用遮挡副本。原图、体态尺度、阶段判断、报告与感言的既有流程保持独立。

## 节点与数据

准备审核后进行独立隐私准备节点，视觉 API 返回逐脸范围与遮挡状态。证据绑定图像 SHA 和提示词版本，在标准体测图、封面原图、训练/生活照成品输入上分别检查。预览和最终绘制只复用证据和贴纸，不在每次绘图时调用模型。新检查必须包含可见后脑；旧记录中已有可靠后脑框可直接复用，旧背向图没有头部框时要求重新检查，不能静默跳过。

会员 `privacy` 保存启用状态、来源、贴纸 ID、准备状态及问题；`_engine.privacy` 保存源文件与证据。贴纸、面部框、绘制版本和原图摘要参与预览缓存键。封面和多图对比先完成取景、缩放，再将面部范围映射到最终照片区域，以同一像素宽高绘制本组成品的主体头像，避免后续缩放造成大小不一致。封面、同朝向对比图与六图拼图分别按真实头部和下颌连接身体：正面用可靠的双耳中点、侧面用可靠的可见耳位置，证据不足时退回各自面部框；头像下缘接近实际下颌。底层遮挡始终留在真实面部位置。单张照片保留独立遮挡副本。来源选择/启停产生新的审核版本，不改写旧成品。

旧任务显示准备入口，按需新增审核版本；不批量覆盖历史。识别不确定或失败时明确提示且阻止未检查照片以“已遮挡”身份输出，不静默回退原图。生图失败可回退标准头像并显示原因。服务重启可继续轮询已提交的生图任务，提交结果不明时不自动重复计费。

设置支持独立生图 URL/模型/Key；默认与同域 Qwen 视觉配置共用 Key，浏览器永不收到密钥。新增请求沿用会话和同源检查，生成与准备由有界后台任务执行，修改审核期间的旧请求不得覆盖新版本。

## 验证要求

验证真实 alpha、透明背景/不透明核心、已遮挡保留与背面遮挡、多脸与侧脸、失败阻断、按会员固定、性别匹配、设置密钥隔离、原图不变、封面几何不变、预览缓存失效和历史版本保留。远程实际调用 Qwen 并在代表会员上检查预览与成品；功能完成后部署、提交推送。

## 装饰头像与背向图（2026-11-08）

生成风格为 `memoji-accessories-expression-v2`。装饰保持小巧，人物保持正面端正，表情随会员固定且重试保持相同提示词。参考图裁剪仅保留头部，提示词要求下巴为贴纸最低点，避免生出脖子影响头颈衔接。标准男、女、通用头像已更新，旧标准 ID 保留以支持历史审核记录；图库只列出当前 100 张。已有专属头像通过“重新生成头像”更新，普通预览不反复生图。

背向头部和可见面部使用同一遮挡规则，六图拼图、各朝向对比图、朝向单图均覆盖。后脑定位优先可靠双耳中点，不使用低置信度的背面鼻眼点；底层隐私遮挡仍位于检测出的头部区域。
