# ZIP 中文目录名兼容修复

2026-11-07。用户上传的 `景田店.zip` 与本机文件大小及 SHA256 相同，上传完整；压缩包内实际存在 `景田店/会员名/文件`，共 9 名会员、88 张图片、4 个视频。失败发生在素材整理阶段。

该 ZIP 的文件名字节为 UTF-8，但没有设置 UTF-8 标记。Python 按 CP437 展示无标记文件名；原逻辑仅尝试 GB18030，转换失败后留下乱码，导致目录不再以“店”结尾。

## 修改

`case-studio/studio/intake.py` 新增统一文件名解码：

1. 有 UTF-8 标记时使用已解码名称。
2. 无标记时还原原始字节，先严格尝试 UTF-8，再尝试 GB18030；兼容 GBK 中文名称。
3. 均无法解码，或 ZIP 标记 UTF-8 但实际字节无效时，明确提示“压缩包文件名编码无法识别”，不继续生成乱码目录。
4. 路径安全检查、重名检查、macOS 元数据排除均在解码后执行。使用 `orig_filename` 保留完整名称，避免 NUL 被 ZIP 库截断后绕过检查；两个不同编码条目若还原为相同路径，拒绝覆盖。

门店筛选、会员分组规则和所有下游最佳实践不变。
