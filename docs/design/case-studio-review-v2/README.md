# 审核体验与 AI 文案增强

2026-11-07。在已部署网站上增加五项能力，保留既有审核内容、素材和成品版本。

已实现并部署，详见 [实施与验收记录](IMPLEMENTATION.md)。

1. 身份节点从报告文字、文档及明确目录标记补全性别与教练。性别缺少直接字段时允许模型解释文字指代，记录原文依据与参考置信度，默认达到 0.90 才采用；不依据人物照片外貌或仅凭姓名猜性别。教练必须有明确角色标记。冲突和不足保留待确认。人工填写优先。
2. 对比图、封面、表格各有“更新展示效果”。数据继续自动保存，输入不触发绘图；按钮只更新所属区域。身份和阶段调整按依赖关系标记受影响区域。
3. 预览按相关内容指纹缓存，独立于全局审核版本。不同朝向预先加载，浏览器 IndexedDB 保存图片，页面刷新仍可复用；退出清理本机缓存。新版图使用新指纹和媒体 ID，不复用旧内容。
4. 封面 AI 面板支持四项选填，编辑提示词，勾选会员体测信息、姓名、会员信息、教练、阶段成果。仅向模型传递选中上下文，生成只回填选中字段，不自动重绘。缺少数据不编造数值、日期、教练或经历。
5. 提示词模板保存名称、提示词、生成字段与注入开关，不保存具体会员数据；支持新建、选择、更新和删除，跨批次复用。

新上传在预处理末尾自动提取身份；已有批次仅补空白且从未被人工修改的字段，避免覆盖正在审核的内容。模型调用和旧批次补全均校验审核版本；审核过程中发生新修改则放弃应用旧响应。

验证包含身份证据/阈值/冲突、教练角色、上下文开关、字段选择、模板持久化、版本冲突、预览独立失效、实际模型生成、浏览器手动更新和缓存复用。隔离目录验收后部署 6008，不影响 6006。
