# 实施与验收记录

2026-11-07。五项审核增强已部署至 6008 的会员案例工作台。代码位于 `/root/apps/case-studio`，沿用 Supervisor、原访问码、模型配置和业务数据。

## 实现

- `studio/identity.py`：预处理末尾读取原始报告图片中的文字与文档文本，记录性别、教练的引用来源、候选、参考置信度、是否采用及原因。性别默认阈值 0.90，可在设置修改；教练必须有明确角色依据。不从人物外貌或姓名猜测性别。资料冲突、不足或模型失败时保留待确认，人工填写与人工清空优先。
- `studio/review.py`、`rendering.py`：三个区域分别生成、分别缓存。文字、照片顺序和取景修改继续自动保存，已有图片等用户点击“更新展示效果”再重绘。第一次进入且没有预览时自动生成。全量成品仍使用同一绘图实现。
- `studio/copywriter.py`、`static/cover-ai.js`：四项文案多选、五类资料按需注入、编辑提示词、模板增删改选。只回填选中字段；生成不自动重绘。接口在模型调用前后检查审核版本，不覆盖并发的新修改。模板只存规则和选项，不存具体会员数据。
- `static/media-cache.js`：三朝向预加载、内存解码复用、IndexedDB 图片缓存；刷新页面仍复用。相关内容修改后，新预览使用新媒体 ID。退出登录清空缓存，持久存储不可用时使用内存缓存。
- `studio/workflow.py`：隔离部署时，网站模块子进程从当前应用加载，避免冻结算法目录中的旧网站代码抢先被导入。原算法入口仍保持其工作目录。

置信度是模型自报参考值，不代表实测准确率。只根据有来源的文本推理，不能确认的性别保留空白；人工仍可修改。

1. 服务器 39 项单元测试通过，包含身份证据、阈值、冲突、教练标记、人工改动保护、子进程隔离、上下文选择、模板管理、版本冲突和分区缓存。
2. 本地 Node 5 项浏览器缓存行为检查通过：并发请求合并、切换复用、退出清理、失败响应不缓存、退出期间请求失效。
3. 独立 QA 数据目录 `website-review-v2-qa`，端口 6010，经 SSH 隧道验收；不向生产审核数据写入测试文案。
4. 真实报告识别：关文博“性别 男性”、董彦琦“性别 女性”均读取成功；景田店/张小飞报告以会员杨子璇为主体，成功提取“教练：张小飞”。前两人无明确教练标记，保持空白。实际调用预处理准备节点，初始审核表正确采用身份结果。
5. `tests/e2e_review_v2.py --model` 真实调用模型，验证所选文案字段回填、模板持久化、编辑不重绘、分区互不触发、恢复旧内容复用缓存。分区预览与全量正式绘图逐图 SHA256 一致，普通预览模型调用为 0。
6. 浏览器验证三个更新按钮、AI 实际生成主标题、模板新建/选择/修改/删除、资料勾选恢复；未选文案保持原值。三朝向各首次下载一次，往返切换并刷新页面后，服务器日志显示额外下载 **0 次**。浏览器无控制台错误。
7. 正式站点 HTTPS 登录、未登录访问拒绝、身份及模板接口通过；6006 首页 SHA256 未变。上线后再次通过 39 项服务端测试。

测试覆盖本次变更与代表性真实素材，未重新跑全量历史图片的 GPU 标准化算法；冻结最佳实践没有修改。
