## 问题与处理

上一修订降低黑衣正面倍率，却将白衣侧面、背面分别额外放大14.3%、9.7%。白衣背面由缺脚进一步裁到小腿；完整度重新分类使整组从768×1792变为768×1689，并取消了原1.07241173纵向展示系数。其他会员像素不变不足以证明被修改组的各朝向没有退步。

现在保留原求解器的候选结果，增加 `proposal_guard.py` 否决器。可靠中立图的肩髋参考原偏差≤3%，候选加重超过5个百分点；同时独立同背景参照显示该候选进一步偏离超过2个百分点、总偏离>8%，才取消该图额外缩放并保留输入、标记复核。背景为至少两张未应用候选缩放的同一实际网格照片，须贴墙、语义置信度≥0.90、横纵格距测量误差≤7%，参照区间跨度≤20%。所有判断使用输入证据，不使用姓名、店名、素材ID分支。

**否决不等于估计正确倍率。** 当前不以网格中位数为新目标，也不以体宽、腰围、脸或服装外轮廓作尺子。证据不足不通过此规则给出新倍率；原求解器其余候选不被联动改写。独立人体/背景差异继续记录并提示复核。因此本次只取消a0078原先额外放大，不能宣称完成精确的真实人体尺度标定。

`coverage.py` 对SAM测得的旧身体边界先与旧最终成品可见范围相交，再投影到候选框。完整头脚保留原余量要求；已经缺脚、贴边、缺腿或缺头的照片，也不能继续损失原来可见的纵向身体范围，容许2个栅格像素误差。投影失败或边界不可靠沿用原审核路径，不降低标准。

`body_scan_group_display/stability.py` 在发生提案否决的组中，复用绑定的基线共同画幅、裁剪框、肩位及展示比例。检查全组素材ID、原图SHA、几何、关键点、真实矩形、身体核心和可见纵向范围；不安全则整组待复核，不使用新缺失状态悄悄更改版式。验证器独立核对引用摘要SHA与最终变换。工作流自动传入基线，开发CLI提供 `--reference-display`。
