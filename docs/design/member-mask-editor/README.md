# 会员头像遮罩人工审核

2026-11-08，基于现有单会员固定透明头像，增加人工位置审核。

- 会员基础设置新增“背向照片显示头像”，默认开启。关闭后仍输出背面照片，只跳过后脑头像；总遮挡开关优先。
- 六图拼图、同朝向对比图、封面分别提供“调整面部遮罩”。六图同时展示前后两排、正侧背三列；对比图按朝向切换 Tab，每个 Tab 左右对应训练前后；封面使用独立 Tab 与左右面板。
- 在最终取景照片上拖动头像，提供方向按钮/方向键微调、删除、恢复自动位置。头像尺寸和等比规则沿用自动布局。各照片独立编辑，立即本地预览，应用后更新对应成品预览。
- 改动按成品范围、照片 ID 和面部序号保存，不以左右位置作为身份。绑定源图摘要、变换矩阵、画幅、检测证据；重新取景或改变素材后旧位置不误用于新照片。自动布局和删除状态分开保留，允许恢复。
- 单会员统一贴纸继续复用，正面/侧面/背向使用同一贴图；不添加底板。原图已有贴纸无法从像素中删除，此编辑器只调整系统新增的头像。
- 数据通过审核版本 CAS 保存；编辑器仅接收当前服务端生成的面板与面部标识，拒绝伪造位置、越界、过期审核或跨会员输入。原照片仅通过已认证媒体接口展示。
- 预览、最终生成、下载共用同一绘制逻辑。分区缓存只在关联设置/位置变化时失效，历史成品保留。

验证包括开关隔离、独立拖动和删除、恢复、六图/Tab 布局、取景变动失效、并发编辑冲突、透明贴纸及真实会员预览，并在服务器部署后提交推送。

## 实现与验收

- `studio/mask_editor.py` 提供独立的认证编辑接口、缓存、坐标校验和审核版本保存。编辑器只生成照片面板，不重复绘制整张宣传图；使用独立锁，避免等待其他区域的文字排版。
- `studio/privacy_panels.py` 在最终画幅上应用按成品/照片保存的位置和删除状态。删除一个头像不会重算其他头像大小。`privacy.mask_back` 控制背向遮挡，包括朝向单图和独立生活/训练照中的后脑。
- `static/mask-editor.js` 提供六图头肩近景、全图切换、朝向 Tab、左右独立画布、拖动、方向键/按钮微调、删除与恢复。六图使用选中照片的共用工具栏，让六个面板同时可见。
- 保存后更新对应区域的展示效果。最终成品和 ZIP 审核说明保留手动设置；封面取景或检测证据改变时失效的位置回到自动位置，避免错贴。

2026-11-08：122 项后端测试、16 项前端行为检查通过。唐怡婷实际素材生成六图、三个朝向对比和封面的编辑面板；隔离 API 验证认证、六面板媒体、移动/删除、旧版本冲突及成品预览。浏览器验证六图同时显示、拖动、独立删除/恢复、应用后更新、朝向 Tab、封面左右框和背向开关。过程没有调用生图或视觉模型，也未修改生产会员审核数据。

隔离验收目录为服务器 `face-privacy-qa/mask-editor-v1/` 和 `face-privacy-qa/mask-editor-api/`；后者保留 API/浏览器测试记录。后端测试日志为 `experiments/mask-editor-tests.log`。部署与备份记录写入 `website/mask-editor-deployment.json`。
