# 网站重构实施与验收

日期：2026-11-07。先记录本目录设计方案，再删除并实现新的 `case-studio` 网站。当前版本连接上传、最佳实践预处理、人工审核和八类成品。

## 实现范围

- 首页 ZIP 上传、真实节点进度与重试；历史恢复审核、查看版本与下载；设置管理模型、品牌、Logo、地址及默认文案。
- 左栏按门店分组，按教练与会员展示。右栏包含身份、前后阶段、对比图文字、封面取景与文字、体测表格五部分。人工身份优先，未知性别不猜称呼；教练为空时显示“未填写教练”。
- 前后板支持拖放和切换按钮，同朝向可指定优先图。审核以资产 ID 绑定来源，乐观锁保存；阶段修改同时影响三视图、VS、单图和封面。
- 封面使用原图、已批准几何及正面双图方案。左右独立固定比例框，可拖动、缩放或按键微调。即时 Canvas 展示完整封面，服务器从原图直接渲染。有效范围外的框拒绝，人物不为适配框而拉伸。
- 表格可编辑五列、增删行及修改标题。新增项真实参与绘图，固定表格高度；无报告照片时只展示表格，二者均缺失则不输出。
- 八类成品复用批准版绘图器。生成绑定完整审核快照，全部完成才发布版本；会员/整批 ZIP 包含审核说明。返回审核生成新版本不覆盖旧版本，不重复调用模型。

## 架构与算法适配

新代码在 `case-studio/studio`；原 `archives.py/classify.py/facts.py/plan.py/preprocess.py/settings.py/tools/` 及旧测试已删除。冻结算法仍位于 `best-practices`，新流程不导入旧网站模块。

分类采用已验证的墙面体测提示词，限定门店目录。拆分 → 单图 v4 → 同组 v3 构建原图/参考/展示数据。报告遵循原始报告优先、汇总补缺、日期重算；同一报告证据适配阶段分类，避免二次转录。矩形取景使用已批准的 `scripts/report_photo_crop`，不做纸张展平。

两项显式兼容扩展：

1. `body-scan-phase-classification --source-manifest` 显式绑定 v4/v3 的 job 与拆分报告，校验清单 SHA、父子来源和像素；不按文件名猜阶段。
2. 成品绘图增加可选文案与 `reviewed_rows` 参数，默认 VS、封面像素保持批准版一致。快照 SHA 同步更新；新增表行不会被默认指标筛选丢弃。

SQLite WAL 保存任务、审核、会话与成品版本，文件存于新 `website/` 命名空间。串行 GPU 队列、受限模型并发、节点独立进程、失败单独尝试目录。正常退出关闭全部子进程组；启动把中断任务标为可重试，避免自动重复付费请求。完成节点复用。

## 边界

- 旧批次显示素材数量并可导入新流程；不把旧实验产物冒充新流程已完成结果。
- 阶段推断/待审仍须核对，成品不印小字，ZIP 审核说明保留未确认资产与缺项。
- 数据缺失或模型转录异常仍可能需人工修改；没有体测图也能生成感言、训练或生活照。
- Logo 已印制的文字属于图片，通过更换 Logo 修改；其余绘制文字提供编辑字段。
- 最多 20 行自定义表格、6 项 VS 指标；过长文案明确返回排版错误，不偷偷截断。尺寸遵循各成品规则，不强行拉伸训练照或生活照。
