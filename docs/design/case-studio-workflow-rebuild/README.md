# 会员案例网站整体重构方案

日期：2026-11-07。目标：以已确认的最佳实践为处理引擎，重建 6008 端口的会员案例网站，打通“上传 → 预处理 → 人工审核 → 八类成品下载”。

## 重构范围

- 删除并重写 `case-studio` 的旧网页、API、上传业务管线及旧测试，旧实现仅通过 Git 和部署备份保留，不在新应用中导入或挂载。
- 另行运行于 6006 的 `portrait-studio` 不属于本次会员案例网站，不删除它；其 Python 环境、模型与历史原始数据仍可作为外部运行资源。
- 保留 `best-practices` 的权威算法。新网站负责状态、节点调度、人工修改、预览和下载，不重新发明图像校正算法。
- 服务器素材、历史批次、已生成版本、模型缓存和密钥不删除。旧记录以历史入口展示，支持从原始素材创建新流程；不能把未经过新流程的旧批次伪装成已完成新流程。

## 页面与信息结构

顶层导航只有：首页、历史记录、设置。首页内承载任务的三阶段工作区，通过任务 ID 和阶段参数恢复位置。

### 首页

初始状态展示 ZIP 上传区、目录组织示例和最近任务。上传后展示三个步骤：预处理、人工审核、成品生成。显示真实节点进度、日志摘要、成功/待审/跳过数量、失败原因和重试入口。

压缩包只将 `xxx店/会员目录/` 下的素材用于生产，参考模板、生产标准和说明文件不进入生产。允许外层项目目录，保留原目录和文件；Logo 可由包内 `logo/` 或设置提供。

### 历史记录

按上传时间展示任务名称、处理状态、会员数、产物数和时间。支持继续审核、查看已生成版本、下载和失败重试。删除代码不删除历史数据；旧批次保留素材数量与导入新任务入口。

### 设置

配置视觉模型的 Base URL、模型名、API Key，品牌名称、Logo、默认地址、对比图默认文案和图片尺寸。服务器模型路径及工作目录不放入普通产品交互。

密钥保存在服务器私有配置中；读取设置只返回是否已配置，不回传完整密钥。空密钥表示保留，明确清除单独操作。设置修改仅作为新任务默认值；已有任务保存自己的配置快照，避免全局设置改变历史成品。

## 三阶段工作流

### 1. 预处理

安全解包与素材清单 → Qwen 素材分类 → 按类型分支：

| 素材分支 | 权威节点与输出 |
| --- | --- |
| 单人体测 / 硬拼接体测 | `body-scan-pairs --split-only` → 合并有效单图 job → `body-scan-wall-v4` → `body-scan-group-display-v3` |
| 训练前后分类 | `body-report-compare` 的报告证据 + `body-scan-phase-classification`，保留规则/推断/待审标签 |
| 报告表格 | `body-report-compare tables`，原始报告优先、汇总补缺、重算日期/变化量；报告取景复用已验证的矩形取景节点 |
| 训练日常 | `body-scan-delivery/training_daily/evidence.sh`，后续按无框 v2 渲染 |
| 会员感言 | `testimonial_album/evidence.sh` → `annotate.sh`，复用内容框与隐私审核规则 |
| 生活照 | 保留 `life_photo` 分类，成品阶段原文件直接输出 |

模型分类适配器采用已验证的墙面体测分类提示词和来源 SHA；不先按旧网站的模糊分数丢图。非体测图不进入体测标准化。渐变拼接、海报背景、几何失败等保留逐张原因。

节点采用独立子进程和磁盘数据包衔接，校验快照与输入。GPU 节点串行，模型节点使用受限并发。每个节点记录参数、输入指纹、输出路径、开始结束时间、状态和错误；重试复用已完成节点，失败输出使用新尝试目录。

照片、报告及节点输出保留为不可变来源；预处理完成后构建统一审核数据和初始成品预览。某类素材缺失不阻断其余成品；核心节点异常明确显示失败，不静默当成成功。

### 2. 人工审核

左侧按店名分组，组内显示 `{教练名}-{会员名}`，无教练时显示“未填写教练”。点击会员切换右栏。右栏固定五个区域：

1. **基础信息**：会员名、性别、教练名。人工输入优先于报告，报告优先于目录。修改后立即同步侧栏；称呼由姓氏和已选性别产生，未知性别不猜“先生/女士”。所有相关成品消费同一份身份数据。
2. **体测训练阶段**：训练前、训练后两个区域，各图显示朝向、来源和审核状态。拖拽切换阶段，也提供按钮满足触屏/键盘操作；允许选择同朝向的优先成品照片。修改通过资产 ID 保存，自动影响 VS、三视图、单图和封面的选图顺序。
3. **对比图文字**：标题、品牌文字、声明、Before/After、VS 字样、称呼、地址、围度文案等均能编辑；朝向标题支持分别配置。Logo 是图片，通过设置替换。提供服务器渲染预览。
4. **封面**：角标、标题、副标题、主文案、介绍、强调文字、品牌和地址可编辑。封面沿用专用正面双图，不使用六图窄裁剪结果。点照片打开取景弹窗，左右分别在可用的完整图上拖动/缩放固定比例矩形框；坐标以归一化原图坐标保存，等比缩放，不拉伸人物。弹窗即时显示双图合成，确认后刷新真实成品预览。
5. **体测对比表**：编辑五列（类型、训练前、训练后、变化量、单位），增加/删除行，修改标题与列头。默认填充报告提取结果；人工修改单独保存，不覆盖原始转录。用户新增指标必须真实参与渲染，不能再被默认九项筛选删除。

所有审核内容保存到任务审核版本中，带乐观锁版本号。失焦/拖拽后自动保存，并显示“保存中/已保存/失败”；切换会员前等待保存，失败不丢失草稿。预览使用版本号隔离，过时响应不能覆盖较新的修改。

图片文件与审核数据分离：文字编辑只重新排版，阶段修改重新配对和更新封面请求；不重复跑分类、OCR 或几何模型。人工取景必须在有效图像范围内，拒绝越界、空框和非等比框。

### 3. 成品生成与返回修改

以本次审核版本快照生成八类成品：三视图、朝向 VS、阶段单图、封面、报告对比、感言、训练日常、生活照原图。按会员浏览图集，每类缺失时展示可解释原因。

- 单会员 ZIP 名为 `{教练名}-{会员名}.zip`。
- 全部 ZIP 内按 `{店名}/{教练名}-{会员名}/` 分组，文件名区分成品类别。教练缺失时使用“未填写教练”占位。
- 对非法文件名字符做替换，路径不允许穿越；同名会员通过稳定 ID 后缀避免覆盖。
- 仅在本次生成全部结束后发布可下载版本；部分素材不符合规则可形成带缺口的版本，运行异常不得混入“生成成功”。
- 可返回审核继续编辑；旧版本继续可查，新结果生成后成为当前版本。下载明确对应某个不可变版本，不在打包中途混入修改。

## 新应用技术结构

新后端使用 FastAPI，SQLite 持久化任务、审核版本、节点状态、会话和生成版本；文件存于现有数据盘的新 `website/` 命名空间。工作队列和任务状态独立于 HTTP 请求；重启将排队或运行中任务标为可重试，不自动重复付费模型请求。正常退出关闭全部节点进程组。

前端采用独立 HTML/CSS/ES modules，移除旧 UI 代码；无外部 CDN 依赖。使用统一 API 客户端、路由、可访问的表单、拖拽阶段板和 Canvas 取景编辑器。整体采用暖白、深色文字和品牌红，图片区优先，密集编辑字段分组。

```text
case-studio/
  app.py                 新 API 与页面入口
  studio/                配置、持久化、安全解包、工作流、审核模型、成品适配、历史迁移
  static/                新三页应用及审核/取景 UI
  tests/                 新服务、数据流、审核联动及下载回归
  start.sh               6008 服务启动
  supervisord.conf       远程托管
```

最佳实践 CLI 由新适配层调用；需要人工文字/表格覆盖时，为成品绘图器增加显式可选覆盖参数，默认行为保持批准版一致，并同步快照清单与测试。不得把开发目录里旧网站模块当隐藏依赖。

## API 与持久化边界

- 会话：登录、登出、当前状态；沿用已有访问码并以安全 Cookie 使用。
- 配置：读取脱敏设置、修改设置、上传 Logo。
- 任务：上传、列表、详情、节点状态、失败重试、历史导入。
- 审核：读取会员审核数据，按版本提交会员字段/阶段/文案/取景/表格修改。
- 预览：保存后的版本按会员生成预览，返回版本号、图像及错误；仅发布匹配版本。
- 成品：启动生成、查看版本、按会员/全任务下载。
- 媒体：只通过任务内登记的媒体 ID 读取，禁止任意绝对路径读取和目录穿越。

上传限制压缩文件大小、展开总量、文件数和路径长度；拒绝符号链接、穿越和加密 ZIP。CSRF 检查基于配置的公网地址及可信代理头，不重现旧网站的端口映射误判；跨站请求不能直接放开。

## 验收与部署

1. 检查旧网站入口与代码已经移除，新网站不导入旧模块；既有数据及冻结算法仍存在。
2. 服务测试覆盖上传/解包、会话、模型密钥脱敏、任务恢复、审核冲突、阶段联动、原图裁剪坐标、任意表行、ZIP 命名与路径安全。
3. 使用服务器真实会员素材执行上传到审核到生成全链路；核验八类输出、缺失记录、身份/文案修改、前后交换、左右独立取景和表格增删。
4. 浏览器检查三个页面、历史恢复、拖拽和替代按钮、取景弹窗、预览更新及下载；保留验证记录。
5. 替换前备份旧网站运行代码和配置引用；新代码先在隔离端口做就绪检查，再切换 6008。数据路径独立，回滚恢复代码而不删除新任务。
6. 方案与实现提交推送；文档写明实际已验收范围及限制，不把历史图片预览当成上传全流程验收。
