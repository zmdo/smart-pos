# 审核即时绘制与后端成品导出

## 目标

审核页在输入、选择、拖拽事件后直接重绘，不等待保存或图片生成接口。浏览器只做确定性的排版和合成；识别、校正、标准化、阶段分类、头像生成继续由既有预处理节点负责。成品仍在服务器保存为不可变版本并打包下载。

## 共用绘制模块

`case-studio/static/render/` 是浏览器和后端 Chromium 共用的 Canvas 2D 模块。使用统一的 1080×1440 逻辑画布、同一字体文件、字体度量、换行、照片选择规则、取景及头像坐标。审核按屏幕大小绘制，导出按配置分辨率绘制。三视图、单方向体测图、同朝向对比图、封面、报告由同一模块绘制。训练日常、生活照、感言沿用已验证的独立成品节点。

服务器提供经授权的素材清单：标准化照片、封面专用校正画布、有效像素范围、肩胯默认取景、头像及面部/姿态定位、报告照片和 Logo。清单不包含服务器路径或密钥；文件使用现有鉴权媒体接口。文本编辑不重新识别、不重新校正，也不重新下载照片。字体切换首次加载字体，随后复用。

后端只允许读取自己建立的静态资源映射，在无外网访问的 Chromium 页面中执行同一模块。导出时冻结审核版本和设置；输出失败必须报告具体原因，不能悄悄输出不一致的备用排版。

## 交互与保存

- 输入立即更新本地模型并在下一动画帧绘制受影响区域；不设 800ms 扫描或防抖等待。
- 保存由变更事件触发。同一时刻一个 PATCH 在途；请求期间的新输入保留，完成后合并并立即保存最新状态，避免排队发送旧版本。
- 本地绘制与保存分离。保存失败明确显示未保存，保留输入供重试；版本冲突不得覆盖服务端或静默吞掉修改。
- 异步加载带会员/页面代次检查，旧会员、旧字体、旧请求不能覆盖当前画面。
- 封面取景和头像弹窗在浏览器内预览草稿，取消不提交，应用后立即更新审核画面。
- 各区域提供“重置”，恢复第一版自动生成内容、该区字体/取景/头像调整；不重做 AI、不删除素材、不回退其他区域。六图重置只还原该成品头像位置，不撤回用户训练阶段分类。初始内容保存在不可变审核第一版中，历史任务同样可恢复。

## 验证与部署

验证配对选择、裁剪有效范围、头像定位、3:4 尺寸、字体/表格布局、输入期间保存合并、冲突/断网、分区重置以及浏览器预览与服务器导出的同模块一致性。用现有九位会员数据另建验证批次，不更改历史审核和成品。只更新 6008 服务，保留 6006。服务器增加固定版本 Playwright/Chromium CPU 绘制依赖，不占 GPU 显存。

## 实现与验证（2026-11-08）

- 前端 `instant-preview.js` 管理每区最新绘制代次，合成到离屏 Canvas 后才替换画面；快速切换会员或字体时旧任务不能覆盖新状态。素材与头像面板缓存，最近三位会员保留内存，原图沿用 IndexedDB 缓存。
- `save-pump.js` 将变更事件合并到一个在途保存请求，保存失败保留草稿并显示重试状态；多端版本冲突仍返回 409。保存回执更新版本和局部状态，不重建输入表单。
- `render_materials.py` 只准备已识别素材，`canvas_render.py` 在固定版本 Playwright 1.56.0 的 Chromium 中执行共用模块。字体用完整字符集 WOFF2，无损压缩并缓存；思源黑体从约 17MB 降至 7.8MB。
- 头像编辑弹窗直接使用本地面板。保存时用同一包的 Node 执行共享几何校验，验证范围、素材和版本，测试保存约 0.19 秒；不重新生成照片。旧 Pillow 头像修改只有在原几何签名仍匹配时迁移，不误套到已换照片或取景。
- 封面拖动同时重绘完整成品及头像；无效取景立即提示并阻止应用。重置只恢复本区文字、字体、取景和头像位置；会员身份、阶段标记及其他区编辑保留。

独立验证批次使用既有九位会员、零模型调用，生成 97 张：42 张朝向单图、18 张同朝向对比、3 张完整三视图、7 张封面、9 张报告、7 张训练日常、9 张生活照、2 张感言。缺项与原版本相同；生活照不加遮挡并保留原文件。

浏览器实测一次封面文字修改重绘约 20ms（后台当时仍在保存）；六图头像调整后约 86ms 更新。这是当前测试机器的测量值，不是所有设备的延迟保证。冷启动要加载照片和字体，加载后普通编辑不调用成品生成接口。

540px 浏览器预览与 1080px 服务器输出的文字布局、取景与头像位置四类校验摘要完全相同（六图、正面对比、封面、报告）。后端自动化测试 159 项、Node 测试 22 项及额外下载/缓存检查通过；另验证头像删除导出一致、越界 400、旧版本 409、旧头像几何兼容。

生产部署前保存代码、SQLite 和历史记录摘要，检查无在途任务。只更新 6008，预先压缩字体，重启后用新验证批次生成，不覆盖原 24 个任务、72 份审核、12 个成品版本。验证资料位于服务器 `verification/instant-review-20261108`。
