本方案因同组侧面/背面劣化已由[独立尺度提案保护](../independent-scale-guard/IMPLEMENTATION.md)替代，下文为历史实施记录。

## 实现

- `solve.py` 独立计算人体/背景差异，保留人体/选中倍率为另一字段。背景建议一致且与人体相差超过12%时禁止人体回退；背景建议自身相差超过8%时，禁止人体单独作超过2%的尺度改变。没有背景证据记为null，不再写误导性的0。
- `grid_consensus.py` 只接管可靠同网格组中“已有缩放提案使格距差距更大”的情况。至少3张、2张中立参考、全部同一贴墙网格、语义置信度至少0.90、横纵网格误差不超过7%，且人体/背景冲突超过12%、格距差距增加超过3个百分点。
- 取原尺度格距的中位数为共同单位；所有图采用目标格距除以各图实测格距的等比倍率。保留原肩部锚点与几何，不以体宽或头部作尺度尺子。
- 原头脚完整度与SAM轮廓、4个百分点新增补边、0.8–1.25倍率范围继续生效。初始中位数不满足时，仅尝试整组统一的±1%至±5%微调。每次均从原图渲染，避免重采样累积；整组通过才落图，任一失败整组回退。不存在每张分别选一个更方便的倍率。
- `verify.py` 检查实际应用倍率与共同格距一致、同组没有部分应用；原图SHA、几何、关键点、等比变换、真实矩形与保留图像字节继续检查。`workflow.py` 将已采用共同网格但仍需复核的结果计入尺度审核清单。
