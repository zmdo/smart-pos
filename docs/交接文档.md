- 分类字段：`kind`(7 类) / `view`(front·side_left·side_right·side·back) / `phase`(before·after·both·unknown) / `background`(网格板·白墙·木板墙·镜面·户外·其他) / `already_masked` / `confidence`。

- 质量：清晰度用 512px 上的 Laplacian 方差（阈值 20）、曝光看均值/截断比例、短边 640；默认丢弃但保留原因，界面可"强制使用/更换素材"（**这两个交互还没做**）。

## 5. 体测图标准化（最近的主线工作，实验已完成，未接进主流程）

**背景**：部分门店把"训练前/训练后"两个人拼在一张图里（对比图），需要拆成两张"标准单图"。

### 5.1 走过的弯路（结论都记在 `09-体测图标准化实验.md`）

| 方案 | 做法 | 结论 |
| --- | --- | --- |
| v1 | 按两人中点切开 | 简单，但隔壁的人会漏进画面、两张人物大小不一致 |
| v2–v3 | 补背景（重画网格 / 周期平移纹理） | 补出来的边缘有明显痕迹，VLM 质检 25 分 |
| v7 | 抠图 + 统一米色背景 | 背景干净，但**鞋/袜边缘被切坏**，且违背"保留原背景"的要求 |
| **v9（当前）** | **领地内取景 + 保留原背景 + 调色 + 质检** | ✅ 可用 |

### 5.2 v9 的关键参数（`case-studio/tools/standardize_pair_v9.py`）

- 分界：**两人之间的中线**（不是"隔壁人物左边界"——那样会把两张源照片的拼接缝带进画面，边缘出现错位条）。
- 缩放：**一对图共用一个 frac**（取两人里最"挤"的那个），画布 960×1920（1:2）。之前按人各算 frac，左边被多放大 3.3%，就是"左边大一圈"的原因。
- 校验：人物像素高度差 ≤0.6%、`neighbor_area_pct = 0`、边缘无残条。
- 调色：以训练前为基准，对训练后做 LAB 均值/方差匹配（强度 0.7）。
- 质检：规则先行（人物完整/留白/邻居露入面积/尺度差），VLM 只做第二道。

> ⚠️ VLM 的判断会误判（例如把"前后服装不同""源图自带的卡通贴脸"当成缺陷，甚至说"两人朝向相反"——实测朝向一致）。**结论要以规则测量为准，VLM 只当线索。**

### 5.3 网格矫正（`case-studio/tools/grid_rectify.py`，实验可用）

Canny+Hough 提线（先挖掉人物）→ 分竖/横两族 → 两组灭点求无穷远线做仿射矫正 → 旋转对齐竖直。

实测竖直线中位偏角：0.97°/1.54°/1.76° → **0.17°/0.0°/0.40°**（p90 < 0.5°）。
**横向还不稳**：Hough 会在人体/器材处检出上百条碎线，横线中位偏角被带偏，所以暂时**只做竖直对齐、不做横向剪切**。下一步建议用 RANSAC 拟合"等间距平行线族"再校正。
